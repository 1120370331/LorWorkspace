# 安蒂

// 梦想教团-最初的使徒

## 角色定位
- 处于封印·历史回放状态
- 可携带3套卡组（分别为司流、司梦、司潮），向堇紫泪滴一样，根据战局局势手动切换状态。

## 基础属性
- HP：102 | 混乱抗性：62 // 作为来宾时：300/164
- 速度：2-6 | 速度骰子：2
- 光芒：4/4
- 抗性：
  | 类型 | 斩击 | 突刺 | 打击 |
  |------|------|------|------|
  | 体力 | 耐性 | 普通 | 普通 |
  | 混乱 | 普通 | 弱点 | 耐性 |

### 神脉：梦之汐-司神-使徒
- 消耗：8
- 品质：Unique
- （不可转移的被动）
- 效果：
  - 拥有3种形态，司潮形态、司梦形态、司流形态，每个形态可配置不同卡组。
  - 舞台开始时，从3种形态中随机激活1种。
  - 切换形态时，用对应卡组等量抽取替换手中的所有书页
  - 司潮形态：
    - 被激活时：获得5层潮，将自身的流、梦转换为等量的潮（视做被消耗）
    - 每次使用潮使一个对敌负面增益提高时：对其施加随机1层虚弱/易损/麻痹/束缚（此效果不受潮影响）
  - 司梦形态：
    - 被激活时：获得7层梦，将自身的潮、流转换为等量的梦（视做被消耗）
    - 敌方骰子造成的伤害与混乱伤害降低30%
  - 司流形态：
    - 被激活时：获得8层流，将自身的潮、梦转换为等量的潮（视做被消耗）
    - 受流强化的骰子命中/反震会追加等同骰子基础值最大值/2的真实伤害/混乱伤害
  // 对于作为来宾的AI，则是每2回合后的回合开始时随机切换一个非当前形态
  // 制作方法参考原版的“堇紫泪滴”的被动（在装备栏获得1费的装备书页，使用来切换，有内置2回合冷却）（先不用做外观变更的部分）
  // 参考堇紫泪滴，应该要重写配卡界面的方法，来支持自定义3套卡组
### 诛灭仇敌
- 消耗：5
- 品质：Unique
  - 本场对局第一次命中敌人时:施加标记为“潮汐的死敌”；与潮汐的死敌拼点时，自身骰子基础最大值加2。与潮汐的死敌:拼点胜利时:造成的伤害/混乱伤害/反震伤害/闪避回复混乱值提高50%；打平时，将此骰子移动到书页末尾再次使用；拼点失败时，受到的伤害与混乱伤害增加50%。潮汐死敌标记的敌人死亡/撤离时可再次标记。
## 战斗书页

### 司神之职
拼点时若本书页骰子基础最大值>对方最大值，则在拼点失败时：强制打平
- ID：9011501
- 消耗：2
- 品质：Rare
- 远近：近战
  - 骰子1：攻击（斩击）2-7
  - 命中时：获得等同本骰子基础值层流
  - 骰子2：攻击（突刺）4-8
  - 命中时：追加本骰子基础值点伤害  
### 潮语
- ID：9011201
- 消耗：0
- 品质：Common
- 远近：远程
- 设计定位：司潮形态的资源回转页，低输出、补手牌、补潮。
- 效果：
  - 使用时：抽取1张书页，获得1层[潮]。
- 骰子：
  - 骰子1：闪避 2-5
  - 骰子2：攻击（打击）2-4

### 汐压
- ID：9011202
- 消耗：2
- 品质：Uncommon
- 远近：近战
- 设计定位：司潮形态的负面状态压制页，最大收益需要4层[潮]。
- 效果：
  - 使用时：消耗至多4层[潮]。
  - 每消耗1层[潮]，依次对目标施加1层[束缚]/[虚弱]/[易伤]/[麻痹]。
  - 若本书页消耗4层[潮]，使目标当前负面效果延续1幕。
  - 上述负面施加本体不再次触发全局[潮]增幅，避免双重消耗；但消耗[潮]本身会触发司潮形态追加随机负面效果。
- 骰子：
  - 骰子1：攻击（打击）5-9
  - 骰子2：防御（格挡）4-8
  - 骰子3：反击（打击）2-6

### 潮启之刻
- ID：9011203
- 消耗：3
- 品质：Unique
- 远近：近战
- 设计定位：司潮形态的自强化页，把[潮]转化为下幕爆发。
- 效果：
  - 使用时：消耗至多3层[潮]。
  - 下一幕获得等同消耗层数的[强壮]与[忍耐]。
  - 若使用时自身非资源类正面效果总层数不低于6，则本书页骰子威力+3
  - 非资源类正面效果不计算[潮]/[梦]/[流]/[黄金之潮]/形态标识/冷却标识等资源或系统标识。
- 骰子：
  - 骰子1：防御（防御）4-7
  - 骰子2：攻击（斩击）3-7
  - 骰子3：闪避 2-6
  - 骰子4：反击（斩击）2-6
