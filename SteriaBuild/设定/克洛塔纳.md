# 克洛塔纳

// 实现这事件的万千梦想，是梦想之女神斯蒂芬妮的宏伟愿景。她了解梦想，但不了解世人，以及世人的梦。
// 建立了梦之城后，大主教安蒂开启了三年一次梦想大考。通过考验之人将获准向神界祈求为实现梦想而得的权能。
// 克洛塔纳是第一个通过考验的梦之城民。他说，那就请给我一切的时间吧。于是时间之神加护于他。
## 角色定位
- 输出型、控制型角色。

## 特殊机制：羽
时间之神的权能体现，它来自时间圣堂的灵鸟，将其附着于物之上变能催化时间的作用。
最大层数：10
拼点时根据双方的速度差，造成以下效果：
当自身的速度最低的骰子与对方速度最高的速度骰子对比，更高时：每一层将使造成的伤害提高10%
党自身的速度最高的骰子与对方速度最低的速度骰子对比，更低时：每一层将使受到的伤害降低1

## 外观机制
本单位使用[幻梦]卡对队友行动槽使用时：播放SP动作
## AI机制
当自身梦数量足够时，若手牌中拥有[幻梦]卡，则回合开始时有50%的概率对一个随机友方单位使用它。
当手牌数量超过自身行动槽时，该效果改为必定触发（如果梦足够）  
## 被动技能

### 梦之汐音
- 消耗：5
- 品质：Rare
- 效果：
  - 拼点时不消耗梦
  - 受到单方面攻击时，消耗1层梦减少3点伤害
  - 每消耗3层梦，下回合获得1层守护

### 散落的愿望
- 消耗：3
- 品质：Unique
- 效果：
  - 使用防御骰子拼点胜利时，获得1层梦

### 梦境共鸣
- 消耗：4
- 品质：Rare
- 效果：
  - 回合开始时，若拥有5层以上的梦
  - 全队友方单位获得1层守护

### 加速音律
- 消耗：3
- 品质：Rare
- 效果：
  - 每回合使超过2个敌方速度骰子改变目标后：下回合获得1层迅捷

## 战斗书页

- 品质：Rare
- 消耗：3
- 远近：近战
- 骰子1：防御（防御）6-12
  - 拼点胜利：使敌人当前书页骰子威力-2

- 骰子3：攻击（打击）2-5

- 骰子4：反击（斩击）2-7
