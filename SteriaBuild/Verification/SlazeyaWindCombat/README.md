# Slazeya wind verification

The current authority is the exact Unity 2019.3.15f1 native fixture, not the old managed doubles.

- `Compile.csproj`: compile production adapter/cache/driver/hit router and the fixture against native Unity/game APIs.
- `run_unity_smoke.ps1`: load the actual bundle, patch the actual DiceEffectManager with the extracted production factory and production hit router, and exercise the player loop. Supply an idle snapshot project and a fresh revision. Includes both facings, all five actions, hit delay, single ring, fixed world impact, miss, wrong target, stale frame, interleaving and cancellation.
- `verify_routes.py`: verify the original five-action routing delta against its task-start snapshot.
- The visual fixture in `VFXSource/SlazeyaWindCombat` additionally checks actual particle playback, render visibility, deterministic replay and Pierce expansion including sub-tick world anchoring.

`Contract.csproj`, `RunContract.cs`, `DriverSpy.cs` and the Unity doubles generated by `prepare_contract.py` are historical candidate-12 evidence only. They do not model target-aware Pierce or the Harmony hit router and are not a current release gate. `prepare_unity_smoke.py` still uses the same exact factory extraction; the historical doubles are neither compiled nor loaded by the native fixture. No current 501-check managed-suite claim is made.

These checks use synthetic Bada transforms and isolated scene playback. They do not claim full live-battle verification.
