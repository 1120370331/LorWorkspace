# 已废弃：克丽丝塔夏旧版特效

本目录保留旧版制作历史，不再作为克丽丝塔夏的构建、预览或部署入口。

新版源目录为 [ChristashaParticleV2](../ChristashaParticleV2/README.md)，统一方法见 [粒子特效制作指南](../../../ModGuideDocs/14_粒子特效制作指南.md)。新版使用独立的 `steria_christasha_particle_v2` 资源和 V2 书页入口。

本目录的旧 `build_and_deploy_bundle.ps1` 只对应历史 `steria_christasha_dawn_combat`；不要用它部署新版，也不要将旧月牙素材当作新版缺失资源的后备。历史脚本、设计和预览仍可用于追溯。
