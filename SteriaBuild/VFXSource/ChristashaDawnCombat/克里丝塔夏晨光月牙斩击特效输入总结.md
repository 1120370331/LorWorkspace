# 克里丝塔夏晨光月牙斩击特效输入总结

本文档整理本轮围绕克里丝塔夏晨光色系月牙斩击特效的全部关键输入、验收标准、反复踩坑和后续制作方向。它不是实现日志，而是需求文档：后续不论由代码生成、Unity 手工制作 prefab，还是参考寒昼 prefab 重做，都应以这里的目标为准。

## 一、总体目标

目标不是做一条透明弯线，而是做一个接近高质量 Mod 水准的「晨光 / 金白色月牙斩击」：

- 主色：黄、淡黄、白，由外到内逐渐变亮。
- 风格：亮黄、亮白、晨光、星光点缀、点阵消逝、飞舞感。
- 形体：大幅度、宽厚、有体积感的实心月牙刀光，不是单线条。
- 动势：从一端开始出现，逐步形成完整月牙，达到峰值后再按先出现先退场的逻辑消散。
- 质感：材质发光、Shader 流动、HDR Emission、柔和 Bloom 承接、扭曲感、多层合成。
- 打击感：要有起刀爆点、主体推进、完整峰值、命中 / 收刀爆点、退场余韵。
- 参考方向：可以参考寒昼、原版和优秀人类案例的层级、时间、材质、粒子方向和参数，但不能直接复制或发布他人资源。

## 二、明确反对的效果

以下表现被明确判定为不可接受：

- 只是一条单薄线条或几段透明 Mesh。
- 中心扩散，不像从发射者到目标的刀刃轨迹。
- 横斩、竖斩方向反了，或外口朝向角色自己。
- 只是 2D 平面贴图，没有在游戏空间中体现方向和旋转。
- 突然出现、整体淡出，没有「从一端切入」和「先来先退」。
- 过曝、爆闪、一坨金光，导致看不出刀光材质。
- 偏橙、偏红，不符合黄白晨光色系。
- 内月牙和外月牙反向包成一个环，而不是实心月牙 + 外发光。
- Mesh 太小或太窄，Shader 再复杂也看不出来。
- 粒子只是随机抖动或漂浮，没有沿刀光切向 / 法向运动。
- 粒子滞后于主体贴图，破坏动作一致性。
- 只靠分段 reveal，像 PPT 分段显示，不像能量流动。

## 三、参考寒昼的正确边界

可以导入寒昼 prefab / AssetBundle 到独立参考工程中分析，但只用于学习：

- 看层级：Mesh、ParticleSystem、Trail、Light、Animator、材质、Shader。
- 看时间：起刀、主体展开、峰值、收刀、退场分别持续多久。
- 看材质：Additive、Alpha Additive、HDR Emission、Dissolve、UV Flow、Noise Distortion。
- 看粒子：发射位置、方向、数量、大小、生命周期、速度曲线、颜色曲线。
- 看 Mesh：主体是否建模、是否有宽度、是否分 Core / Body / Glow / Shadow。

不能做：

- 不能直接把寒昼 prefab、贴图、Mesh、Shader、材质打进正式 AB。
- 不能改色后发布为自己的资源。
- 不能把参考资源留在最终构建目录。

正确方法是：在 `ReferenceOnly` 工程里拆解思路，然后在本项目中用自己的 Mesh、贴图、材质、Shader 和 prefab 重建。

## 四、最终结构要求

特效应拆为至少 6 层，而不是一个 Mesh 解决所有问题：

| 层级 | 作用 | 要点 |
| --- | --- | --- |
| Core 核心刃线 | 提供最锋利、最亮的刀刃感 | 窄、白 / 黄白、HDR、高亮、短命 |
| Body 主体月牙 | 提供主要形体和饱满度 | 宽厚、金黄 / 淡黄、实心、非透明 |
| Outer Blade 外刃 | 叠在当前内核月牙外口处 | 淡黄到深黄，和主体同样受 Shader 控制 |
| Glow 外发光 | 提供光溢出和能量感 | 大、软、金色，不要橙红，不要爆闪 |
| Shadow / Dark Dust 暗部 | 防止塑料感，制造厚度 | 宇宙黑、土色、棕黑，低调压边 |
| Spark / Cosmic Shard 粒子 | 星辰碎片、边缘飞散 | 沿月牙周围外层随机均匀分布，有方向 |
| TopStar / BottomStar 十字星 | 起刀和收刀视觉锚点 | 独立发光 Mesh / 粒子，扩展后淡出 |

## 五、月牙 Mesh 形体要求

月牙 Mesh 必须先把「形」立住，不能靠粒子和光效补救。

### 1. Mesh 必须是大面积宽厚月牙

要求：

- 高度要足够大，能形成明显大斩击。
- 宽度必须远大于普通曲线，不接受细线。
- 中段鼓起，上端和下端收尖。
- 外缘更厚，内缘更锐，但整体仍然是实心月牙。
- 内月牙不应和外月牙反向包成环。
- 内月牙不需要单独衰减，应该实心接到外月牙；外月牙负责衰减。

核心原则：

```text
要做 crescent body，不只是 crescent path。
```

### 2. 建模参数理解

- `height`：月牙从上到下的整体尺寸，决定是否像大招。
- `width` / `outerWidth`：月牙横向厚度，决定是「面」还是「线」。
- `bellyWidth` / `outerBelly`：月牙中段鼓起程度，决定是否饱满。
- `innerWidth`：内侧收口距离，决定刀刃是否锐利。
- `outerWidth > innerWidth`：外缘厚、内缘薄，形成真正新月。

如果只增加高度不增加宽度，结果仍然会像一条长线。

### 3. 推荐宽度逻辑

月牙应使用宽度函数，而不是固定窄带：

```text
t = 0 顶部
t = 1 底部

width(t) = baseWidth + peakWidth * sin(t * pi)
outerWidth(t) = width(t) * 1.10 ~ 1.25
innerWidth(t) = width(t) * 0.70 ~ 0.88
```

视觉目标：

- 顶部窄但不能断。
- 中段宽，像完整刀光体块。
- 底部收尖，但仍有厚度。

## 六、方向与锚点要求

方向和空间位置是验收重点：

- 横斩必须以角色中心为锚点，朝向敌人方向释放。
- 横斩应该在水平层面形成月牙刀光，不能往身后释放。
- 锚点之前偏高，应向角色前方移动约 25%，并降低到合理命中高度。
- 竖斩应从上往下出现，不能从下往上。
- 竖斩的月牙外口不能朝向角色自己。
- 命中点必须贴近目标，不能偏到目标身后。
- 如果引擎层面的 3D 平面旋转受限，应通过 Mesh 顶点算法、透视压缩、Z 偏移、宽度差等方式模拟空间角度。

## 七、月牙出现与退场逻辑

月牙不是突然出现，也不是整体直接淡出。

### 1. 出现逻辑

要求：

- 从月牙一端开始出现。
- 沿月牙路径逐渐扫过。
- 先形成完整月牙，再进入峰值。
- 扫过应该由 Mesh 材质 / Shader 控制亮色填充，而不是单靠粒子填充。

### 2. 峰值逻辑

必须有一个明确的完整峰值窗口：

```text
起刀：0.00s ~ 0.10s
主体拉开：0.10s ~ 0.26s
完整峰值：0.26s ~ 0.38s
收刀 / 命中：0.36s ~ 0.48s
退场：0.48s ~ 0.80s
```

前面的段不能在后面的段还没出来时就消失，否则永远看不到完整月牙。

### 3. 退场逻辑

退场必须满足：

- 先出现的部分先退出。
- 先形成完整月牙，再从弧口处向弓面处溶解消失。
- 不能整片直接降低透明度。
- 贴图 / 主体淡出应比外光更快，外光可以多留一点余韵。
- 消散过程要有势能曲线，整体越来越快，而不是匀速消失。

## 八、Shader 需求

用户明确要求：月牙 Mesh 必须增加能量流动 Shader，产生流动感和扭曲感。

### 1. Reveal 变量

Shader 应使用随时间变化的 reveal 变量控制区域：

```text
reveal = f(time)
visible = step(pathT, reveal)
edgeBand = smoothstep(reveal - edgeWidth, reveal, pathT)
```

含义：

- `pathT` 表示顶端到末端的路径进度。
- `reveal` 表示当前扫到哪里。
- `edgeBand` 是扫过边缘的高亮带。

### 2. 亮度梯形

月牙亮度不是平均透明，应采用梯形分布：

```text
centerPlateau = 中心白金亮度平台
sideFalloff = 两侧快速衰减
```

视觉要求：

- 中心有一个明显白金亮度顶的横区域。
- 两侧快速衰减到淡黄 / 金黄。
- 外层是黄，内层是淡黄 / 白。
- 亮度要够实，不要完全透明。

### 3. HDR Emission

要求：

- 十字星和月牙 Mesh 都要配置 HDR Emission。
- 不需要在 Mod 内强行设置 Bloom；Bloom 应由游戏 / 图书馆本身后处理承接。
- 本项目只负责把材质的 HDR Emission、Additive / Alpha Additive、颜色强度配置正确。
- 光亮度不能过曝，否则会变成一坨金光。

### 4. 能量流动和扭曲

Shader 应包含：

- UV Flow：沿月牙路径轻微流动。
- Noise Distortion：低频噪声扰动，避免死贴片。
- Dissolve：退场时按路径和噪声溶解。
- Edge Glow：reveal 前沿有亮边，体现能量推进。

不要让竖条、高频噪声或细纹理抢走主体轮廓。

## 九、颜色与亮度要求

配色必须从橙红修正为黄白晨光：

- 外层：金黄 / 淡金黄。
- 中层：淡黄。
- 内核：白 / 白金 / 黄白。
- 暗部：宇宙黑、土色、深棕黑，用于压厚度。
- 外发光：金色，不要橙色、红色。

亮度要求：

- 主体不应太透明，应是「非透明发光体」。
- 白金 alpha 可以提高，形成实心亮核。
- 光效强度要比之前低，避免爆闪。
- Glow 范围不能过大，否则材质被光盖住。
- 发光层不能把主体贴图完全淹没。

## 十、十字星要求

十字星不是普通静态贴图，也不是缩小消失的图标。

### 1. 结构

- 十字星应是独立的 ParticleSystem / Mesh 层，贴在月牙 Mesh 两端。
- 顶部十字星是起刀锚点。
- 底部十字星是收刀 / 命中锚点。
- 应围绕十字星向外发射光线，扩散并逐渐减暗。

### 2. 动画

预期表现：

```text
内核出现 -> 十字发光 Mesh 向外扩展 -> 周围光线扩散 -> 逐渐淡出
```

要求：

- 先扩展，再淡出。
- 不要收缩消失。
- 要有闪烁、发光、边缘特效。
- 顶部星不要挂太久。
- 底部星不能太晚出现，应跟随月牙扫到底部的峰值。

## 十一、粒子与星辰碎片要求

粒子不能只是随机抖动，要服务于刀光动势。

### 1. 月牙内部粒子

最初曾考虑用白色粒子从上到下扫过 Mesh 内核，后来修正为：主体亮色填充应由 Shader 控制，粒子只辅助质感。

保留要求：

- 粒子可以从月牙端部单点向各方向扩散。
- 粒子不能超出月牙主体范围太多。
- 粒子应逐渐填充感，而不是随机漂浮。
- 方向应与月牙路径相关。

### 2. 边缘粒子方向

粒子速度应来自局部切线和法线：

```text
velocity = tangent * A + normal * B
```

要求：

- 主方向沿刀痕切线运动。
- 次方向向外法线轻微扩散。
- 不是统一往右下或原地抖动。
- 粒子与主体贴图同步，不应明显滞后。

### 3. 宇宙星辰碎片

需要在月牙周围外层增加「宇宙星辰碎片」：

- 中心：随机小型多边形。
- 内部颜色：宇宙黑、土色、棕黑。
- 外边缘：一圈小亮白 / 黄发光。
- 分布：随机、均匀，围绕月牙外层。
- 作用：提高立体感和星光点缀，而不是遮挡主体。

## 十二、外刃 Mesh 要求

在当前内核月牙外口处叠加一个外刃 Mesh：

- 使用和主体相同的 reveal / flow / dissolve 控制。
- 颜色从淡黄到深黄。
- 作为外刃发光和轮廓强化。
- 不应和内月牙反向形成环。
- 外刃负责边缘衰减，内月牙负责实心接合。

## 十三、横斩、竖斩、突刺、打击的关系

本轮体验中，突刺和打击相对更可接受，斩击问题最大。

要求：

- 横斩必须是从发射者到目标的大型刀刃轨迹，不是中心扩散。
- 竖斩必须从上往下，方向不能反。
- 迸射流星也应使用竖斩表现。
- 近战突刺不能做成爆炸式远程特效；应是长横轴穿透。
- 打击应是自上而下的纵劈 / 砸击。
- 远程命中特效要明显，有拖尾轨迹和命中点，不是屏幕上两个点。
- 远程释放者面前应有直立圆形法阵，法阵要有竖直层面旋转角度并扩大 50%。

## 十五、验收标准

每版进游戏前后按以下标准检查：

- 缩小看，一眼能认出完整宽厚月牙。
- 最先看到的是月牙主体，不是纹理线、粒子点或一坨光。
- 色彩是黄、淡黄、白金，不偏橙红。
- 中心白金亮核明确，但不过曝。
- 外发光是金色柔光，不淹没主体。
- 月牙从正确端出现，方向正确。
- 有完整峰值窗口，而不是永远半截。
- 退场是路径溶解 / 先来先退，不是整体透明度降低。
- 十字星扩展后淡出，有光线扩散和边缘发光。
- 粒子沿月牙切向 / 法向飞散，不是随机抖动。
- 命中点贴近目标，锚点不偏高、不在角色身后。
- 运行中不卡死、不未响应、不产生过量粒子或无限循环。

## 十六、核心结论

这个特效的核心问题不在「弧线够不够复杂」，而在表现层结构是否完整。

正确优先级是：

```text
宽厚主体 Mesh
+ 白金核心亮线
+ 金色外刃
+ HDR Emission
+ Shader Reveal / Flow / Dissolve
+ 起收刀十字星
+ 切向 / 法向粒子
+ 宇宙星辰碎片
```

不应继续只调中心线、分段 reveal 或粒子数量。先把大月牙 Mesh 的体块、颜色、方向、Shader 流动和退场路径做对，再继续调星尘和细节。
