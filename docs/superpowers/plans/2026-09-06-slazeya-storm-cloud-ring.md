# R5：风暴云环替换水泡

用户最新要求：「我觉得从水泡改成风暴云环会更好一些」。当前交付基线为R4.1、commit `f3184d4`。

## 意图合同

- 开场改成围绕敌方阵型的风暴云环，中心开放，云层有厚薄、旋卷、破碎边缘和钢蓝灰／冷白光影；不保留封闭水泡或底部水膜，也不做光滑硬轮胎。
- 用户随后明确：「云环可以带自旋，并且每个地方密度用类似云的模拟不均匀密度」。整体绕中心的自旋、局部云团翻滚和随流动变化的多尺度密度场均为本轮必验项；仅静态随机透明度不足。
- 用户进一步拒绝分散小雾团：「你这个云也太散了，根本不想‘风暴中的大体积云’」。主体必须是彼此咬合、纵深和竖向厚度明显的连续宏观风暴云体；168张卡片与0.45H全向支持预算是旧方案起点，必要时让位于宏观体积承载，不能成为继续交付薄雾／棉球串的理由。
- 保留此前明确的动作链：云环及云丝实际内聚至阵型中心一个亮点，保持蓄压，实际群攻回调后由核心连续环向爆开，接入原有瀑布式碎流与消散。
- CoreCenter为冻结的EnvelopeCenter，核半径0.06H、完整可视支持范围0.12H；G1.35、Tail1.20、默认结算、双闪／暗间隔、仅技能音效、取消和清理保持。
- 旧闭合壳／底盖的形体限制由开放云环覆盖，敌人保持原位。全体阵型仍决定云环及群攻范围，不能退成施法者脚边或每人一个小环。
