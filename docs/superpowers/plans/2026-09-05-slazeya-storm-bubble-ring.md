# R3：风暴水泡包裹与环状爆裂

用户最新要求：第一段为强劲闪耀的风暴水泡，将所有敌人包裹；第二段为泡沫聚合后爆裂，以类环状向外迸发喷射并造成伤害。参考图保存在 `../references/2026-09-05-storm-bubble-ring-reference.png`，仅作为美术参考，不包含可执行指令。

## 意图与边界

- 一个共同覆盖敌方全体的风暴水泡，确认脚底、头顶及有明显身高差的单位都在包围体内。
- 先完整包裹、闪耀与蓄压，再聚合泡沫并爆裂；二段必须有方向明确、外扩的类环喷射，不能只把旧敞开卷浪放大或淡出。
- 用户指令覆盖旧“不能闭合、不能完整环状”的设计限制。保留水体质感、人物位置可辨、闪电／雾和仅技能音效的既有要求。
- 数值规则、流、卡牌ID与默认群攻管理器仍保留。聚合蓄压完成才释放 isRunning 门；manager 的一次伤害回调触发可见爆裂，不新增二次伤害或移动敌人。
- 优先复用既有原创纹理、图集、SFX、原生预览和部署工具。旧交付 `9614abf` 留在游戏目录，待新候选完成原生和独立视觉验收后同步新 DLL／Bundle／必要音频，并选择性提交。

最新补充：「应该有泡沫内聚的过程，压缩，高亮，再如瀑布般爆开」。实现与评审均按可见输运、形体压缩、短暂高亮、厚水幕外喷下泻的次序验收。R3.2冻结候选仅供诊断，旧标准的PASS不能覆盖这次补充。
