# 斯拉泽雅「倾覆万千之流」Round 2：旋卷巨流与倾覆水冠

日期：2026-09-05。研究／视觉设计交付，供主线程审定后交 Chandrasekhar 实施。

用户最新要求：「这个特效是不是太素了，我希望是3A级别的。」本稿据此取代 [Round 1 规格](2026-09-05-slazeya-storm-mass-design.md) 的简化视觉方案，撤销固定 5 个 mesh、3 个粒子系统、160 粒子预算及一轮精简限制。原生预览、同源驱动、无脚本 prefab、默认 manager 伤害桥接继续保留。品质通过可见的形体、材质和动态结果评审，不由系统数量或“AAA”命名决定。

## 3. 美术构图：从螺旋带变成会倾覆的水体

### 3.1 轮廓与主次

延用已验证的敌方 XZ footprint、脚底中心和 H。首轮比较保持原相机、H=6、Rx=9.6、Rz=7.6 和原五人站位，不用拉近相机或放大整个 root 掩盖品质差距。

主卷浪约占有效水体视觉面积 55–65%，次卷浪约 25–30%，低位汇流和空隙中薄雾承担其余部分。这是构图权重，不是增加同心层的配额。

| 大形 | 聚集时 | 爆发时 |
| --- | --- | --- |
| **PrimaryBreaker：主卷浪** | 从后侧／斜后侧宽底卷起，环绕约 190–230°；有一处主压力峰，而非等宽环。宽面高度约 0.55–0.90H，厚浪唇在局部达到 1.4–1.7H。前方留开放缺口。 | 卷唇先向外翻，主水幕掀成宽而不规则的扇面；主峰约 1.8–2.1H，只占局部扇区，不围成同高墙。 |
| **SecondaryBreaker：次卷浪** | 短些、低些、窄些，约 90–140°；从对侧接入，晚主卷浪约 0.10–0.15s 形成。流向一致，曲率与压力峰不同。 | 晚主浪约 40–70ms 翻出，把主峰之后的运动延续出去；不能形成左右镜像双翅。 |
| **InflowSheets：贴地汇流** | 2–3 个宽窄不等的低位水舌，从外围贴地扯向浪腹，末端有断续泡沫；少量水雾把它们与主浪脚连起来。 | 分裂成向外跑开的浅水舌，尾随主冠；取消完整亮圆环与连续仪式盘。 |
| **BurstCrown：倾覆水冠** | 不预先亮起，不先摆一个隐形完整莲花。 | 从实际主／次浪唇衍生出 4–6 个不等宽外翻瓣／大片水刃：一主、两次、余者很短；中间有 V 形撕口、翻背和拉丝。 |

角色可读性靠空间留窗、前低后高和材质差异实现，不能继续把所有水都压到同样低 alpha。聚集前侧高密度水幕不应持续遮住所有人的头胸；主高峰放在后／侧方，前方仅有低浪、少量飞沫及短暂越过人物的水刃。允许强峰值有短促遮挡，但 B+0.25s 后头胸轮廓必须重新清楚。

方向可以由固定战斗相机和 footprint 在初始化时确定前／后，美术左右选择可随本次固定 seed 改变；初始化后不随相机抖动重新摆造型，不改变阵营判定或 root 定位。

### 3.2 必须做真实卷曲截面与连续形变

原 `Ribbon(int index)` 的薄条几何全部替换。主／次浪不能只在旧 ribbon 上加宽，再用整体 scale 和 yaw 完成全部运动。

每张浪面使用沿弧参数 s、从浪脚到浪唇的横截面参数 q。截面至少有「浪脚—鼓起浪腹—肩部—越过肩部的卷唇—回钩薄尖」五个形状控制点。浪唇需要在径向越过肩部再回勾，局部法线明显转向；不是一个连续倾斜平面。侧视也必须辨认这段卷曲。

可执行路径：Builder 生成拓扑一致的汇流、压缩卷起、外翻倾覆三个关键姿态，使用 mesh 顶点数据／附加 UV 通道携带形变目标，shader 由显式 `_Gather`、`_Overturn` 在同一张面上连续变形。也可使用同等可验证的参数化曲面函数。每条主浪约 96–128 段弧向、12–16 段截面已足以表达曲率；避免为性能先将其退回四排薄带，也不需要流体求解器。

沿 s 改变宽度、压力峰位置、径向收缩量与卷唇角度：浪脚缓慢移动、肩部先抬、浪唇后卷；尾部逐渐追上，形成内部剪切。最多叠加小幅低频湍动约 0.02–0.05H，不能让高频噪声改写宏观轮廓。s 两端用不对称尖收／拉丝收口，不留整齐斜切带头。

压缩结束后保持已卷起的大形，只继续局部流动。回调到达时记录实际卷浪角位、wave phase 和浪唇发射位置；倾覆从这个状态连续发展，不能将预排水冠重置到另一个方位。喷溅初速度继承该处切向＋外向速度，减少无来由的中心放射针。

## 4. 材质、纹理与局部光照

### 4.1 四个有不同职责的视觉区

1. **浪腹暗部**：深海蓝 `#082F46`／`#124C69`，形成卷唇下方的吸收色和密度。局部可以比旧水带更实，主体正常区 alpha 起点 0.55–0.80；暗部不是另叠一张黑色透明壳。
2. **中间水幕**：`#167AA1` → `#45BACD`，宽面上有团块密度、缓慢旋卷的中等纹理和厚薄变化，是画面面积最大的水体。
3. **亮浪唇／泡沫**：`#9AE7EB` → `#E7FFFF`，集中在受力肩部、外翻前沿和有限泡沫团。厚度与断口变化明显，不能变成沿所有边缘等宽的白描边。
4. **稀薄喷雾**：浅青灰、柔边、内部有明暗团块，盖在浪脚／掀起边缘附近。远离浪头的雾迅速降密度；不能整片蓝雾遮住场地。

### 4.2 Built-in 自有光照，不依赖场景后处理

保留 Gamma 色彩空间作为当前已验证候选的比较条件，不在本任务切换全工程颜色空间。新主 shader 使用变形后几何法线＋低强度流动法线细节；至少能读出卷唇顶面、朝向不同的浪腹、被卷唇遮住的暗面。

用效果自身的宽面积方向光参数塑造亮面，使用 wrap diffuse／半球渐变、浪唇遮蔽 mask、厚度吸收色与克制的菲涅尔补光。方向参数属于本效果，初始化后稳定；不能依赖游戏共享 Scene 灯或新增全场 DirectionalLight。菲涅尔只支持薄缘与翻背，避免整个轮廓变成均匀霓虹线。高光须有随水纹变化的粗糙度，不能出现大片稳定光滑的树脂高光。

非等比 footprint 缩放后法线／切线要正确转换；形变后不能继续使用姿态一的静态平面法线。可对同一个参数化形变函数取 s/q 的偏导，或从变形后的几何和 UV 重建相符切线框架，供微法线使用。此要求是体积品质的关键，不可用新增一层 glow 代替。

主水体推荐预乘透明 `Blend One OneMinusSrcAlpha`、`ZWrite Off`、正常 ZTest；输出 RGB 只预乘一次，dissolve／总 fade 同时约束 alpha 和 RGB。少量喷沫亮点可用 Additive，自己的能量也须在生命周期末归零。不要给全水幕使用加法混合，更不要新增背景抓取、屏幕折射、Bloom 或改变多相机后处理。

相对亮度组织：水幕为稳定中间亮度，受力浪唇通常约其 1.5–2 倍，命中时仅局部浪唇再短促抬高；蓝色浪腹须在峰值保持可见。峰值可有几处近白亮斑及小范围软辉，不能整片白化。数值以最终 Gamma 原生渲染为准；本稿的色值和比例是调色起点，不是把色值写入就通过验收。

### 4.3 原创纹理资产必须重新制作

废弃当前 `FlowRGBA` 的贯穿正弦排线和纯径向 alpha 雾图。新资产由专属离线生成工具或 Builder 确定性生成，允许新增同目录小型生成脚本；实现时必须输出可检查的 mask／atlas 板。可使用手绘原创输入替代生成结果，但不能未经目视检查直接把噪声叫作水纹。

| 资产与建议规格 | 生成／绘制方法 | 必须避免 |
| --- | --- | --- |
| **WaterBodyRGBA，1024×512** | R=宽面密度团，G=肩部及浪唇泡沫团，B=定向破裂阈值，A=宽面覆盖／端缘窗。以稀疏不均匀控制点形成粗细变化、分叉汇合的流束，叠多尺度 domain-warped noise；主要结构沿 s 流动，横向能看到团块压缩。 | 将高频 `sin(v*N)` 重新换个频率；覆盖全宽的等距白线；颜色、密度、侵蚀全部复用同一噪声导致碎沙。 |
| **WaterNormalFlow，512×512 或 1024×512** | 从同一中尺度流动高度场求局部梯度生成法线，另提供缓慢变化的流向扰动。主面仅有约 3–6 组可读的宽折流，细纹低对比，局部细节随泡沫打断。U 周期连续，避免周期重置造成黑闪。 | 新法线与密度纹理无关联；高强度波纹把水面变成凹凸塑料；每帧随机生成纹理。 |
| **FoamSpray flipbook，4×4 帧、1024²** | 原创扇形喷沫／薄片：初帧宽浪唇拉出几根粗细不同的水指，中帧薄膜开洞、边缘结滴，末帧只剩分离水滴。16 帧使用同一拓扑／种子随时间连续拉伸、侵蚀、下坠，软硬边并存。 | 16 张互不相关噪声闪烁；白矩形卡片；整扇齐头等长水指；让 flipbook 取代主三维卷浪。 |
| **MistDensityLighting flipbook，4×4 帧、1024²** | 同一组低频团块随局部旋卷场平移、膨胀、稀释；通道分开密度、受光团、底部暗部和 alpha。shader 再以青白色族着色。边缘稀薄、内部有大团遮蔽，形体随年龄破开。 | 径向柔圆不断放大；同一圆图随机重叠堆成云团；黑烟、脏灰煤烟或过亮蒸汽墙。 |
| **Droplet／Spindrift 小图集** | 4–8 个不等长水滴、弯曲短水丝、泡沫碎片；头重尾细且方向一致，供真实 Billboard／Stretch 粒子使用。 | 所有粒子都是同一根直针；大小和朝向完全均匀。 |

密度／法线／控制 atlas 使用数据纹理设置（sRGB=false），有颜色的输入按其真实用途设置。atlas 单格至少保留羽化 gutter，mip／双线性不能采到相邻格；小尺寸预览检查闪烁和边缘串格。Texture Sheet Animation 或自有采样须使用真实粒子年龄；固定种子、每次重播一致。16 帧之间若明显跳帧，用双帧插值，而不是增加曝光掩盖。

大形、中尺度流动、细泡沫的权重参考约 60／30／10。细节关闭后仍应是一股有体积的旋卷巨流；缩至 320×180 时泡沫可以合并，卷浪与命中仍必须一眼可读。

## 5. 粒子编排与新的时间轴

原三个 ParticleSystem 可以替换为按职责分组的系统，例如 GatherMist、CrestSpindrift、BurstSheets、BurstDroplets、BurstWisps、ReturnMist。需要多少个由空间职责和材质决定；不保留旧数量断言，也不建立新的“至少 N 层”审美标准。可先按几百个活粒子预算设计，再依据实际 overdraw 和运行时间约束，而不是先固定 160 个导致体积不足。

喷溅必须成束：主浪唇发出较粗的薄片／喷沫群，次浪较小且稍后；小水滴跟随其尾缘分离，近景少而清楚，远景细而淡。每组用不同寿命、速度和受力方向。低位雾跟随水幕脚与落点，不在整个椭圆等密度发射。

**建议冻结 `GatherDuration=1.35s`、`TailDuration=1.20s`。** 沿用 `TriggerBurst()` 唯一爆点，不能从聚集时长直接推导爆发。B 始终表示实际 manager 回调时刻。

| 时间 | 大形与运动 | 亮度／附属层 |
| --- | --- | --- |
| G=0–0.25s | 贴地水舌先被向内拉，主浪腹开始鼓起；范围从开场即可辨 | 深蓝湿雾、少量青色水丝，亮度克制。 |
| G=0.25–0.90s | 主浪肩部逐段升起、卷唇后跟；次浪延迟形成，径向收紧、切向速度增加 | 密度团随水体拉伸，泡沫集中出现在曲率／剪切较大的浪唇。 |
| G=0.90–1.23s | 风暴最饱满，浪腹向内压，局部高峰约 1.5H，仍有角色窗口 | 中间水幕对比充分，暗腹与亮唇同时成立。 |
| G=1.23–1.35s及等待 | 宏观运动略减速，卷唇蓄压；表面流动和细雾继续，不能完全定格 | 明亮面积稍收窄至压力区，等待实际回调。1.35s 只释放 manager 门。 |
| B=0–0.07s | 当帧启动主浪唇外翻，不先额外缩一遍；最强运动／前沿集中在前两三帧 | 局部青白峰值、很短的水刃亮面，初始喷沫从旧浪唇发出。 |
| B=0.07–0.25s | 主冠先外掀、次冠跟进，几处不等宽水瓣拉开；整体外缘约 1.10–1.20R，最高局部约 1.8–2.1H | 宽白沫头、半透明蓝水幕和暗翻背共同存在；碎滴滞后。 |
| B=0.25–0.55s | 水冠薄膜沿流向被撕成大缺口，外翻动量转成下降；不是继续等比放大旧螺旋 | 峰值退去，水滴仍可见，落点出现局部雾与泡沫。 |
| B=0.55–0.90s | 下坠碎片、低位退水，角色场地重新打开 | 低亮雾最后滚动扩散；停止新增高亮水丝。 |
| B=0.90–1.20s | 水膜归零，余雾散净 | 所有通道和粒子归零，controller 完成并交既有清理。 |

形体要重，但整体仍是约 2.55s＋manager等待的单次群攻；避免把每个相位都拉长来制造所谓大片感。特效不执行真实吸怪、抛起、碰撞或额外伤害。

顶层 `AB_GroundRoot/AB_StormRoot/AB_BurstRoot/AB_ParticleRoot` 可以保留；其下建立明确的 PrimaryBreaker、SecondaryBreaker、InflowSheets、CrownLobes 等美术节点。`TriggerBurst` 只启动／锁定视觉状态，不含游戏对象伤害处理。

Prefab 仍只有 Unity 原生组件，无自定义 MonoBehaviour。所有 mesh／纹理／材质是序列化资源，运行时不逐帧创建 Mesh／Material。共享驱动保留显式 delta 和有限手工 `ParticleSystem.Simulate`；不能把粒子自动 Play 与手动模拟同时开启。更换粒子发射点和数量时继续统计真实 `AliveParticles`。

透明排序优先用非重叠的主次曲面与空间留窗；必要时按几何连续的前／后扇区拆 mesh，而非创建两层等比外壳。拆分边界属性、曲线及 UV 必须连续。游戏有多相机和旧 `UnityEngine.PostProcessing`：不改其相机层、全局灯、全屏曝光／滤镜作为此效果的前提。

## 7. 原生预览与高质量验收门槛

先保存 Round 1 对照不动。Round 2 输出独立目录 `preview_exports/slazeya_storm_mass/round2/`，保留相同战场与黑底机位；可以额外输出材质近景，但不能只交近景。输出包含 shader 及资源回读后的 Bundle hash、共享驱动 hash、真实 callback 时间、颜色空间、相机参数、每相位原生活粒子计数。

原生代表帧：G=0.25s、G=0.85s、G=1.28s、**B+0.033s 命中瞬间**、**B+0.20s 水冠最大展开**、B+0.45s、B+0.80s、B+1.25s。最大展开曲线目标放在 B+0.20s 左右；若实际调整，manifest 与该代表帧必须同步到实际极值。按 B 相对采样，不能沿用固定旧 `CallbackTime=1.45` 下的过时文件时间误称同一相位。旧版 `_Flash` 在 B+0.083s 已衰减约 83%，不可再用这一张当作整个爆发的唯一证据。

至少提供 30fps 完整原生序列／MP4 与 GIF，模拟维持 60Hz；峰值附近补看 60Hz 连续 6–10 帧以排除跳形。所有代表帧、GIF 和视频必须从同一 Bundle 回读、同一共享 runtime controller 路径导出，不能为截图另调曝光、提前爆点或重绘水冠。动态中的聚集重量、释放转换和余势连续性是最终判断依据；最好看的一张峰值图不能替代动态通过。

| 门槛 | PASS 必须看到 | REVISE 条件 |
| --- | --- | --- |
| **主形／体积** | G=0.85／1.28 有宽浪腹、卷唇和前后空间；主浪明显大于次浪，能辨认局部压力峰 | 仍主要是三条规整带；闭合透明锥；加厚只是复制壳。 |
| **材质** | 同一浪面上同时有深腹、中间水幕、亮浪唇；中尺度密度随流向变化；泡沫有团、有断、有疏密 | 均匀平行条纹、全表面等亮、带纹纱布、凹凸塑料、靠颗粒噪声撑亮度。 |
| **形变** | 浪脚／肩／唇先后卷起，B 附近同一浪唇连续外翻，次浪略滞后；相邻帧能追踪流体结构 | 仅整根 scale／rotation；回调换一套不相连的造型；随机噪声高频抖动。 |
| **爆发对比** | 无需看时间标签也能将“压紧”和“倾覆峰值”分开；短促亮前沿之后是大形展开与喷沫 | 聚集和爆发只差亮度／几根针；峰值是整幅白屏；数百毫秒持续同一曝光。 |
| **消散** | 薄片先撕开、滴落；大水体先退、雾后退；B+1.25s 清空 | 全部同时 fade、整圈收成点、仍残留亮环／循环烟。 |
| **角色尺度／可读性** | 固定全景中阵地级主浪清楚，施法者侧干净；压缩阶段能辨认五名受方，峰值后迅速恢复头胸可读性 | 所有人一直浸在厚雾；主浪只在贴脸近景成立；扩大 root／改相机掩盖原尺度下单薄。 |
| **渲染一致性** | 不依赖场景灯与新后处理，黑底与暖灰战场都能读出形体；实际原生 atlas／粒子、Bundle 回读、同源驱动 | 只在额外 Bloom 下好看；预览重绘／替代粒子；游戏无法加载脚本／shader。 |

两个快速美术诊断可直接复用同一次预览场景：关闭喷溅／光晕，主卷浪仍须厚而有方向；缩至 320×180 或灰度观察，主次形状和命中节奏仍须成立。这些是检查结果的手段，不是让玩家关闭功能，也不要求另建庞大测试体系。

原有 15 项玩法验收结果作为已知桥接基础；视觉驱动和时长变化可能影响终止时间、空资源、等待及回调幂等，主线程对受影响候选重验即可。最终画面由独立评审按本稿与用户新要求返回 PASS／REVISE／BLOCK；技术门禁通过不替代视觉 PASS。

## 8. 实施交接与本次边界

建议实施顺序：先完成主／次卷浪截面及三态形变，带基础法线／厚度色在全景中检查；随后完成水幕 mask 和浪唇泡沫；再加入从浪头衍生的喷沫／薄片与体积雾，输出完整原生序列。三部分都是本轮质量目标，阶段检查用于尽早发现造型错误，不是把半成品当最终交付。

任何技术阻碍只回报具体问题，例如变形法线失真、atlas 串格或某个 renderer 被游戏相机过滤；不能因第一版难做就退回均匀丝带、降低全体 alpha 或增加全屏亮度。保留外部美术资源的参考边界，制作本项目自己的几何和图像。

本研究仅新增此规格：未修改源码／Shader／资产／旧报告，未重建、运行 Unity 或部署，未派生代理；没有生成概念图，也没有把外部参考截帧冒充原生效果。正式实现与构建由 Chandrasekhar 承担，审定、原生独立评审和后续同步由主线程推进。
