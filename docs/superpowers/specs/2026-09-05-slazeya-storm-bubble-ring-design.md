## 2. 一个确实包住全体的水泡

### 尺度：宽地面截面的椭球上部＋封闭底盖

不能把球的最低点放在地面：这样地面截面是一个点，分散脚底必然在泡外。采用**椭球与脚底平面相交的上部**，底下有同截面水膜底盖；椭球中心位于角色身体中段，最低点在地面之下，所以角色脚底所在高度仍有足够宽度。

使用当前受方集合，冻结初始化时每人的世界脚底、头部及有效身体 bounds；S 至少含每个脚点、头点和身体 bounds 八角。**常用 H 继续服务材质、粒子和比较尺度，bubble 的中心／轴长由每名受方的实际世界样本另算**，不能仅凭中位数 H 推断所有人的头高，也不能将不同地面高度的头顶都归到同一个 feet.y+H。实际身体 bounds 沿用现有身体 renderer 筛选，避免把特效挂件算入。若个别身体 bounds 缺失，用其有效高度和保守身体宽度合成诊断样本并记录回退，不能静默漏掉该单位。

按下列方法得到最小蓄压形态的包围参数，之后所有聚集形变都不得缩到它以内：

```text
Cx/Cz = S 的水平包围盒中心
Cy    = (min(S.y) + max(S.y)) / 2
Ry    = max(0.85H, max(abs(S.y-Cy)) / 0.70)
a0/c0 = 已有地面 footprint 半轴与 S 水平半跨度+0.15H 的各自较大值
k     = max(1, max_P sqrt( (((Px-Cx)/a0)^2 + ((Pz-Cz)/c0)^2)
                            / (0.90^2 - ((Py-Cy)/Ry)^2) ))
Rx=a0*k, Rz=c0*k
Q(P)  = ((Px-Cx)/Rx)^2 + ((Py-Cy)/Ry)^2 + ((Pz-Cz)/Rz)^2 <= 0.81
Yg    = min(S.y, 所有脚底y) - 0.02H
```

Ry 的构造保证分母为正。Q≤0.81 是内侧余量，不是把样本放到表面。最终仍计算 `maxNormalizedRadius=max(sqrt(Q(P)))`；若超过0.90，三个半轴统一乘 `maxNormalizedRadius/0.90` 后重新检查，并按新轴长重建地面截面。地面任意高度 y 的可用半轴为 `Rx/Rz × sqrt(1-((y-Cy)/Ry)^2)`；必须检查**真实脚底高度**处的截面，不能只检查椭球赤道。

例如原阵型的一个脚点 `(4,0,-3)`，若仅把旧 Rx=9.6、Rz=7.6 用于中心 `(10,3,1)`、Ry=5.1 的椭球，Q≈1.014，仍然在泡外；按上述 k 扩张才会包含。身体角点可能要求进一步扩大，不能将这个例子的 k 当固定常量。

闭合期轴缩放最初以1.05–1.08为调试起点；按用户后续强调的压缩张力，最终R3.8由1.14倍压到1.00，绝不低于1.00，并已通过同镜头视觉和全体身体包含检查。小幅表面湍动只向外位移。这样泡沫收紧时仍包住人。root继续在受方世界坐标，不挂施法者，不随受伤／死亡重新收缩到幸存者。

### 拓扑与极点

参数曲面可用 `x=Cx+Rx*cosφ*cosθ, y=Cy+Ry*sinφ, z=Cz+Rz*cosφ*sinθ`；φ 从 `asin((Yg-Cy)/Ry)` 到 π/2，θ 为完整 2π，底盖接同一圈顶点。初值约 96–128 周向段、32–48 纵向段；上极点使用焊接顶点／扇接，底盖闭合。不能跳过最后纬圈留下天窗。

椭球法线由梯度 `((x-Cx)/Rx²,(y-Cy)/Ry²,(z-Cz)/Rz²)` 得到，做正确变形／缩放转换；极点不能 normalize 零切线。身体主纹理采用周期经向映射，顶部渐变切到无极点的 XZ 投影或局部三平面映射；接缝两侧坐标、法线与控制量相同。**R2 的 q 端部羽化和 `water_body_rgba.a` 空白 gutter 不得用来擦除泡顶或赤道接缝**；闭合外形的最低覆盖由新材质独立保证。

## 3. 第一段：明亮、旋卷、蓄压，但能透见人物

水泡在 G=0–0.18s 迅速建立全体闭合轮廓，随后增强内部流动；不是先从小球放大穿过敌人。用一个表面表达蓝青水体、局部深蓝吸收带、宽亮泡沫旋流和细雷光。整体比 R2 更闪耀，不能再以大面积暗蓝平面作为主要观感。

包裹感来自连续顶面、两侧、前膜、后壁和地面接触圈。前膜可较透（alpha 调色起点约 0.20–0.35），边缘与后侧密水区较强（约 0.45–0.70），但前膜仍有连续水纹、折流和辉光，不开大洞。人物位置通过透射式着色／前后密度差读出；不要求所有人物始终无遮挡地显示原色。避免不透明白球，也避免只有几根边线的肥皂泡／护盾。

复用现有宽密度、水流、法线粗糙度 PNG，形成 2–3 股宽窄不等的螺旋泡沫流在**同一个闭合体上**绕 Y 卷行；大形完整，局部流速和泡沫疏密不同。亮区用青白 `#BCEFF8→#EEFFFF`，主体用亮蓝青 `#238DB8→#60CFDF`，深蓝只托住涡沟和背部厚度。使用效果自有法线光照、克制菲涅尔和局部发光，保持现有 Gamma 环境，不新增全屏 Bloom／曝光或场景灯。前／后透明面如需分 pass，用同一封闭几何的剔除区分，不叠多层等比泡壳。

**泡沫聚合**：G=0.95–1.35s，上半泡沫沿螺旋向下、下半沿螺旋向上，汇入约身体中下部高度的爆裂纬带（起点可取 `Yband≈最低脚底+0.50–0.65H`）。带宽由约 0.25H 压到 0.08–0.12H，泡沫密度与亮度集中；壳上其他位置的泡沫减少，但水膜不断裂。必须看得出纹理／泡沫块在搬运汇聚，不能只把一条新亮环淡入。显式 `_FoamGather` 驱动采样输运与带宽，动画到终值后持续流动并等待回调，不周期倒流。

## 4. 第二段：壳破裂，环状外喷

B=实际 `GiveDamageFromManager` 回调。准备（包括聚合蓄压）到 G=1.35s 才 `isRunning=false`；未收到回调不能先破壳。manager 已正常处理防御和伤害，视觉层不额外 GiveDamage／TakeDamage，不按喷射波前再打一次。

| 时段 | 必须发生的形变与视觉 |
| --- | --- |
| G=0.18–0.95s | 闭合水泡持续加速旋卷，人物全在其中，亮泡沫与深水沟交替形成压迫感。 |
| G=0.95–1.35s及等待 | 泡沫汇入纬带、外形小幅压紧但不缩穿身体；1.35s 后仅保持蓄压并等待 B。 |
| B=0–0.033s | 爆裂带有短促青白强峰与雷光，同帧启动壳体撕开。先出现互相连接的非规则裂口，不是上段继续完整膨胀。 |
| B=0.033–0.10s | 壳的上／侧片从纬带向外剥离、弯折、被拉成薄片，中心迅速打开；被聚合的泡沫与裂口一起变成外喷前沿。 |
| B=0.10–0.25s | 类环状喷射达到主峰：四周均有水幕／水丝／雾浪的向外动势，3–4 个扇区更强，其余连接环形运动，不是孤立几根针。 |
| B=0.25–0.55s | 开裂水片继续外飞并下坠，主泡轮廓消失；环浪向外跑、边缘继续分裂，喷沫带出水雾。 |
| B=0.55–1.20s | 局部落点低雾、碎滴和退水散净；所有新旧层及声音按既有总长结束。 |

**最短可行破壳方式**：Builder 将一个闭合壳划为约 12–16 个周向扇区与少量纬向区域，破裂前片区边界位置／法线完全连续；片区标识只用于 B 后形变。`_Rupture` 使相邻片向不同外向量平移、翻折和变薄，带着沿流向扩展的不规则撕口；顶部也剥离，不能永远剩完整顶盖。水片先发生位移／弯折，侵蚀随后追上。不能只做 noise dissolve、整球 scale，或把它表现成硬玻璃碎块。

纬带位置取壳在 Yband 的实际截面。喷射初速度以椭圆向外法线 `N=normalize(cosθ/Rx,0,sinθ/Rz)` 为主，切线 `T=normalize(-Rx*sinθ,0,Rz*cosθ)` 为辅；初值 `v≈H*(3.5–5.5)*N + H*(0.2–0.6)*T + H*(0.3–0.9)*Up`，按方向／寿命衰减，随后下坠。泡沫图集卡片必须沿各扇区的外喷方向摆放／拉伸，不朝统一屏幕上方排成重复冠。

近侧环浪低、宽、较清晰，快速跨过脚前；远侧稍高、稍窄、亮度收敛，透过泡内人物后方可读；左右两翼提供最清楚的侧向喷射。各扇区速度／开裂时间可有 20–50ms 差异，不能逐个慢放一整圈。B+0.18–0.25s 的主要外沿目标约为爆裂带初始半轴的 1.35–1.55 倍；远端低密度，限制强亮水片持续穿到施法者区域。类环状的连续性由水片与雾浪交接建立，不靠符文、硬亮圆线或全等齿轮花瓣。

闪电保留既有 B 附近一强一弱两次短闪、局部反光和暗间隔，重新锚定泡沫爆裂带／裂口，不能继续引用旧浪唇。第一段的持续闪耀由水体与流动亮沫承担，无需增加无限频闪或重做声音。保留 `gather_loop.wav`、`burst_tail.wav`，G1.35／Tail1.20 与 B 同帧触发完全兼容，故无理由拉长或新合成音效。

## 2026-09-05 用户补充：内聚、压缩、高亮、瀑布爆开

用户原话：「应该有泡沫内聚的过程，压缩，高亮，再如瀑布般爆开」。第一段后半必须呈现可区分的动作次序：已有白沫块沿水泡向内汇流，泡体随之压紧，集中泡沫短暂高亮蓄压，再由实际伤害回调触发爆开。不能只把发射位置收窄或淡入一条亮环来代替输运；最小泡体仍须包含全体身体样本。

爆开主形为有厚度、速度差和下坠重量的水幕及白沫：围绕全体向外喷出，随后像瀑布一样向下倾泻。强弱扇区和撕裂水舌形成近似环向动势，避免细而完整的发光圆圈。验收需按连续帧看到内聚→压缩→高亮→外喷下泻，不能仅由一张峰值静帧证明。既有G1.35／Tail1.20、回调、音效及镜头保持。

**一眼拒收**：①第一段仍像两张山峰水幕或每人小泡；②任一受方头／脚在泡外、泡顶开洞或明显UV纵缝；③用大缺口换人物清晰度，失去共同包裹感；④第二段只有整球放大／淡出，完整壳一直留到尾声；⑤喷射不是围绕全体的向外环形动势，仍是重复朝上的冠状贴片；⑥全屏白化、持续不透明白雾，或修形改动触及自定义伤害／流规则。
