## 2. 冻结接口、唯一中心与终点尺度

保持 `Footprint` 拟合与现有 public 生命周期。推荐 Controller 暴露下列只读诊断值，shader 接收相同数值，不另算一套时序：

```text
H                = Footprint.Height（现有参考身高，不随收缩重算）
CoreCenter       = Footprint.EnvelopeCenter（初始化时冻结的世界三维中心）
CoreRadius       = 0.06 * H（有限水核几何半径）
CollapseProgress = smoothstep01((GatherAge - 0.82) / 0.46)
CoreVisibleLimit = 0.12 * H（所有可视支持范围的硬上限）
```

`GatherAge` 爆前取现有累计时间，B 后取捕获值；`smoothstep01(x)=saturate(x)^2*(3-2*saturate(x))`。正常路径 G=1.28 已收成核，1.28–1.32 完成蓄光；**G≥1.32 至实际 B 前，所有水面、白沫、滴、雾和发光必须落在以 CoreCenter 为球心、0.12H 为半径的球内**。H=6 时水核半径 0.36，完整可视直径最多 1.44。这个上限包含粒子卡片四角、拉伸长度、微小位移和光晕，不能只约束粒子中心。

水核顶点／持久白沫中心距离 C 不超过 0.06H；白沫卡片最终边长建议不超过 0.07H（方片半对角约 0.0495H，总范围小于 0.12H）。关闭核心期 velocity stretch；168 个身份可保留，通过尺寸与透明度降低重叠，不能把原 0.09–0.21H 大卡片原样堆到一点。核必须实心可读、只有一个亮度重心，不能留下环形空心、第二亮点或外围细亮线。

`Footprint.Center` 继续只是现有根坐标原点：CPU 世界点转粒子局部时减它；shader 所在节点仍以 `EnvelopeCenter` 为原点并带 `EnvelopeRadii` 缩放，世界相对位移须按现有 `p/_Radii` 合同转换。禁止重复加 C／重复乘半轴。`BandY` 可留兼容字段，但不再决定任何收束终点、爆发出生点或光源锚点。初始化后不因受伤、死亡或名单变化移动 C。

## 3. 一条连续的水体／白沫收缩路径

| 时间（G 为技能开始后的秒数） | 动作 |
| --- | --- |
| 0–0.18 | 在原全体拟合范围建立一个闭合风暴泡；不从中心小球向外穿人建泡。 |
| 0.18–0.82 | 完整包裹，2–3 股不等宽白沫沿水体旋卷，深水沟与局部亮薄膜交替。 |
| 0.82–1.28 | 顶、底、前、后和两侧一起向 C 收拢；白沫保留身份，随壳向内旋进，世界距离持续减小。 |
| 1.20–1.32 | 后段收缩与局部蓄光重叠，最终只余一个小白核和钢蓝灰边缘。 |
| 1.32–实际 B | 保持小核位置与上限，低幅内部流动；1.35 开 manager 门。不得重新膨胀、发外围粒子或提前爆发。 |

可直接在现有 `BubblePoint` 抽出未坍缩闭合形 `P0(theta,q,cap,phase)`，冻结原 1.14 初始尺度及底盖拓扑，再施加以下径向场；shader 使用同一公式：

```text
c = CollapseProgress
d = P0 - C
u = rotateY(normalizeSafe(d), 0.55*c)   // 总额外旋进约 32°，保持周向接缝一致
Pcollapse = C + u * lerp(length(d), CoreRadius, c)
```

径向湍动随 `(1-c)` 衰减，晚期不允许独立向外鼓包；白沫可在同一个场中多旋进 0.15–0.30rad，停止上／下半球向 `BandY` 的旧 q 汇聚。原来带纹理的水面随几何搬运，颜色和 alpha 只塑造材质，不用把大泡溶掉、另淡入中心球代替收缩。

**底盖必须一同抬向 C。** 不要直接把旧 `ClosedScale` 改成趋零后重算 `GroundY/(Ry*scale)`：这既把底盖钉在地面，又会使开方越界／纬度退化。先生成有限的初始封闭点，再映射到小核；极点、底盖中心和接缝都用有限法线回退。shader 的地面接触 alpha 仅在早期有效，随 c 关闭，避免收成核时沿旧世界地面裁掉半个核。

`GatherFoam` 的 168 个固定 seed 继续承担可见输运，不增加另一圈粒子。早期 `CrestSpindrift` 的存量也必须随收缩场向内搬运并缩短卡片；从 G=0.82 停止普通自由外喷。等待 B 时不再累计／补发普通发射额度。其他已经存在的 gather 滴／雾同步收拢、缩小；不能让壳到中心而旧存量在外围活到回调。中途自然寿终的小滴可以消失，主水体和主白沫必须实际抵达中心。

核心亮度由同一小核表面和收进来的白沫承担。建议 `Charge` 在 1.20–1.32 上升，之后保持约峰值的 0.75–0.85，直到实际 B；保持期只有核内纹理运动，不重复蓄压／扩圈。无需新增核 prefab 或透明外壳。

## 4. 所有爆发出生点统一到核心与传播波前

`B = GiveDamageFromManager` 实际触发时刻。`TriggerBurst` 捕获小核位置、相位和白沫状态；B=0 的首批 `EmitSector(5)` 可以保留时机，但必须来自小核内，初始粒子尺寸也须满足 0.12H。当帧不允许把旧外围水面、喷沫、雷或雾打开。

最小改造：保留现有 `RingLobes` 四个强弱水舌、14 个扇区、撕裂／下坠和末段侵蚀。把旧 `RingPoint` 的展开形作为目标形 `Pout(theta,q,b)`：横向尺度仍来自初始 `EnvelopeRadii.xz`，高度基准改成 C.y，保留向外倾斜与后续落地裁限。实际渲染点改为：

```text
b = BurstAge
w = smoothstep01(b / 0.23)
Pjet = lerp(Pcore(theta,q), Pout(theta,q,b), w)
```

`Pcore` 位于 C 周围半径 0.06H 内；整个环面在 B=0 均在小核，w 推动真实顶点经过所有中间半径。内缘随时间离开核，形成有厚度的外喷水带，不是长久连着 C 的发光圆盘。原 `BubblePoint` 的外围 hinge 破壳分支停用：小核可在 B+0–0.06s 内开裂／退光，把视觉权重交给从它喷出的水面，不得恢复旧大壳再撕裂。

持久白沫从各自捕获的 `Pcore_i` 连续进入相同扇区波前；不要沿用固定 3–5H/s 的旧外围粒子速度，让白沫与新快速水面脱节。自由滴从**当前到达的水面**脱离，继承波前切线速度后减速、下坠；新生卡片尺寸随 w 增长，不能在 B=0 出生一张 0.8H 喷片。

| 原入口 | 统一取样规则 |
| --- | --- |
| `EmitSpray` / `EmitSector` / `BurstSheets` / `BurstDroplets` | 首批用捕获核；后续批次取 `Pjet` 当前水面，随机偏移也乘传播进度。 |
| `EmitWaterfallStreaks` | 沿当前 `Pjet` 的已展开水舌出生，方向继承向外动量并下坠，不回退到旧外围。 |
| `EmitMist`（lift / return） | lift 贴已到达的波前；return 仅从已到地面的该水流落点起雾，未到地面就延后／略过该簇。 |
| `ApplyLightning` / `_LightningPosition` | 第一闪从核连接到当时已到达的水流，B=0 的全条雷也在核限内；第二闪锚当前波前。继续 0 与 0.10s 的双闪、各≤0.05s、暗间隔。 |

建议取样函数在 CPU 与 shader 共享同一数学合同，所有辅助层调用它；不要为每个发射器各自估计一条近似外围圆。波前没有到达的位置禁止出生任何强亮水片／雷光。仍可保留原来靠施法者一侧的强度／距离衰减。

| 回调后 | 应看到 |
| --- | --- |
| B+0、+0.017、+0.033 | 小核喷出短水舌，半径逐帧增长；外围没有凭空出现一整圈。 |
| +0.10–0.23 | 从核向外推进的水带展开为近似环向动势，四股不等宽主流最强，弱扇区以断续薄水／碎沫交接。 |
| +0.23–0.55 | 外沿仍外飞，水舌向下翻、薄裂、拉丝；允许复用 R3 06 已有下泻细节，去除规律卷曲小卡片花边。 |
| +0.55–1.20 | 只剩落地低雾与碎滴，按既有尾长清空。 |

## 5. 配色、厚薄和局部光的可执行起点
