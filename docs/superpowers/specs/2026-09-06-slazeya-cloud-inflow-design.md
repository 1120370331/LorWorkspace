以下距离除以H，C为CoreCenter。b=.35是局部压缩入口，e=.25，k=b(b+e)。定义严格单调的行程坐标：

```text
P(r) = ((r+e)^2-(b+e)^2)/2       r>=b
       k*ln(r/b)                 0<r<b
I(s) = sqrt((b+e)^2+2s)-e        s>=0
       b*exp(s/k)                s<0
q0=(x0-C)/H; r0=length(q0)
r=I(P(r0)-A(G)); F(x0)=C+H*q0*(r/r0)
q=(x-C)/H; r=length(q)
r0=I(P(r)+A(G)); F^-1(x)=C+H*q*(r0/r)
rho(x,G)=rho_old(F^-1(x),G)*min(8,1/J)
J=(r/r0)^2*P'(r0)/P'(r)
```

原点单独返回C；log/除法使用有限下限，先排除旧场支持之外的逆样点。rho_old指现有完整支持、孔边、W4/W8/W16和侵蚀公式；孔判断必须用逆样点，不能拿世界坐标旧孔裁掉入流。

G0.82–1.28内单调C1插值A，起止速度为零。令p=(G-.82)/.46、rmin=min(innerRadii)/H、Rmax=(旧box中心距C+半对角)/H；锚点A(0)=0，A(.5)=P(rmin)-P(.92rmin)，A(1)=P(Rmax)-P(.018)。用无过冲单调Hermite连接。若末半段过快，只将起点提前到.65并重新归一化；Gather1.35、Tail1.20、manager回调、SFX不动，回调冻结A。

已有云体就是发射源，无新增随机出生。外段速度dr/dG=-A'/(r+e)：内侧头部快、外侧尾部慢，径向间隔增大、连续向核补入；r<b后速度=-A'r/k，头部减速、尾部追上压实。前半段径向云瓣不缩短，横向保留至少92%；原.5H/.25H级结构保留为约.46–.55H/.23–.275H，不能承诺所有方向严格刚性。噪声周期仍2H/1.2H，禁止再乘common scale；后半变形来自输运梯度。
