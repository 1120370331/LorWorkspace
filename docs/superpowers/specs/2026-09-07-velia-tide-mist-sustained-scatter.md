# 潮雾晨光：延长现有照射与减缓遮光漂移

2026-09-07，研究/设计，**主线程已批准并冻结，以主线程合同为唯一准据**：首骰.72s、次骰.77s，原+.18s亮度保持至.48s，尾段.24/.29s，入场后共享运动时钟.65倍；预览Begin99、回调117、205帧（0–204）、完成断言frame200。本文仅恢复已批准合同，不提出新设计；未改生产或运行Unity。

## 诊断与最小时间合同

当前 `Pulse` .04s升亮、保持至.07s，首骰.27s/次骰.32s归零。日心、halo、beamLight、cloudLight、fogColor均由它驱动。host等 `PulseFinished` 才放行下一骰；末骰则 `Finish()` 后再等.40s淡出。只改shader不能延长host寿命，只改总时长也会改变早期回落。`_HitStrength`独立使用.14s，必须保留。

**主线程批准两骰各延长.45s：保留前.18s的整个亮度曲线，停留.30s，再把剩余回落延长.15s。**这比把峰值1一直维持更忠实于R7，也避免 `spreadPulse=pulse*(1+.75*travel)` 在传播后期意外增亮。单骰连同末尾.40s清理小于现有2秒原生WaitUntil边界。

确定性实现合同：保留原始 `baseDuration=.27/.32`，令 `holdEnd=.48`、`PulseDuration=baseDuration+.45`（.72/.77）。`Pulse`计算使用局部求值年龄 `a`：

```text
t = 实际 _pulseAge
t <= .18: a = t
.18 < t <= holdEnd: a = .18
t > holdEnd: a = .18 + (t-holdEnd) * (baseDuration-.18)/(PulseDuration-holdEnd)
Pulse = 原R7曲线(a, baseDuration)，含原Smooth/clamp
```

分母就是新尾段长度：首骰.24、第二骰.29。保留实际 `_pulseAge`单调推进；`PulseFinished`比较实际年龄与新的.72/.77。不是暂停controller或修改Time。第二骰shader的 `travel=smoothstep(.035,.18,_PulseAge)`严格保留，禁止改为局部求值年龄、减速时钟或放宽区间。无新增时间累积字段；重复回调/BeginDice去重沿用原实现。

## “光束移动”实际对应什么

当前shader中日心位置和三道 `beam` slope/width/spread都是常量，**没有光束扫动/平移速度**。看到的微动来自 `cloudUV`的慢漂移与1.5px褶皱扰动改变 `cloudShadow`透射；另一种明显变化是+.035–.18s的云面受光传播，用户明确要求保留后者速度。

不新增光束运动。主线程已批准将“减缓光束移动”落实为现有遮光漂移变慢：在 `cloudUV`中将**漂移与褶皱扰动共用**的时间改成 `motionTime=min(elapsed,.32)+max(elapsed-.32,0)*.65`。`.32s`入场曲线仍读真实elapsed，云的形状/幅度/位置公式不变，旧低雾时钟不变；绘制cloudBank与cloudShadow都调用同一个cloudUV，保证遮光依然贴云缘。这会同时减缓极轻的云漂移，必须在实施报告中说明，不能称为减慢原本不存在的beam sweep。

**不单独让阴影读较慢时间而厚云继续原速**：那会让透射与当前遮挡轮廓不一致。无需独立optical clock或更换云函数，也不得降低早期传播速度。`.32s`交接处时间连续、不跳位；后续云与遮光缓动共同为原速的65%。
