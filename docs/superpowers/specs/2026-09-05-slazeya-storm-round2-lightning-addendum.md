## 1. 闪电：两次局部放电，不延长效果

H、R 和 root 继续使用已验证的受方 footprint。所有位置是 root 下的 XZ／Y 世界尺度，不能跨到施法者侧或屏幕边缘；不连人物头部，不从屏幕上空劈下一条贯穿全场的雷。

| 元素 | 位置与形状 |
| --- | --- |
| 主短闪 | 在风暴眼**内侧的上方空隙与主浪唇之间**斜向跳接。以 `CrestPoint` 当前主压力段的 q≈0.75–0.92 为浪唇端点，另一端向眼内侧偏约 0.45–0.75H、略抬 0.10–0.20H；实际长度约 0.5–0.9H。选择后／侧方可读空隙，避免横贯全部角色。 |
| 次短闪 | 第二脉冲移到相邻或次浪压力段，贴浪唇切向／斜径向展开，长度约 0.3–0.6H；不重复完整主闪，不绕成电圈。 |
| 分支与宽度 | 每次 1 条主线＋至多 1 条支链，支链长主线的 20–35%、宽约一半。白芯宽 0.008–0.014H，含青色柔边总宽 0.025–0.040H。4–7 个不均匀折点形成电性；端部收尖，局部折向偏移约 0.03–0.06H。 |

Builder 预制 2–3 个固定 seed 的折线路径变体，借现有 branch mesh 的双排三角带方法；每个变体可把支链并入同一 mesh。白芯和柔边在**同一 mesh 的横向 UV shader**内形成，不叠多套壳，不加 TrailRenderer。材质近白芯 `#E9FFFF`、青边 `#73DDEB`，边缘弱于芯；其细线可以比水体亮，亮面积必须明显小于水冠。

设 B=实际 `TriggerBurst` 回调时刻，脉冲由 `_burstAge` 确定：

| B 相对区间 | 行为 |
| --- | --- |
| B+0.000–0.050s | 主短闪：回调当帧已有小幅可见能量，0.016–0.033s 为峰值，0.050s 归零。 |
| B+0.050–0.100s | 明确暗间隔，所有电弧不可见；水冠正常继续展开。 |
| B+0.100–0.150s | 次短闪：0.116–0.133s 达主峰约 50–65%，0.150s 归零。 |
| B+0.150s 以后 | 不再放电，最大水冠与消散交回水体。聚集／等待期间不自动频闪。 |

每次脉冲开始取实际浪唇位置和切向，脉冲内可随其小幅运动；折点和分支形状保持稳定，不能每帧随机抖动。第二次脉冲仅切换一次预制变体。两个时间窗有界且幂等；跨帧跳过窗口时保持应有状态，不排队补发迟到闪光。禁止正弦无限闪烁、真实灯、全屏曝光／相机滤镜、伤害／拉怪／击退代码。

## 2. 浪沫 → 卷起水雾 → 落点低雾

统一复用 **`SteriaBuild/VFXSource/SlazeyaStormMass/source_assets/round2/mist_density_lighting_4x4.png`**。该图集已具备成团密度、顶部受光、底部暗部和淡退，沿用当前粒子 shader 原生 AgePercent／StableRandomX 与双帧插值。不得换回柔圆、不重新生成一套雾资源。

**必须先纠正覆盖通道的重复衰减。** 主线程已核实 Dalton 的素材采用 28 层体积积分／受光／遮蔽，A 已包含 `density^0.88 × lifetime`；本次实际读到粒子 shader 仍使用 `alpha=data.a*data.r*_Alpha*i.color.a`，再乘 R 会重复压低密度，是脚底雾几乎不可见的具体原因。雾分支改为以 `data.a × 局部opacity × i.color.a` 表示覆盖，R 主要参与厚度、吸收色／光照；不再乘 R，也不额外重复乘一遍 atlas 已含的完整寿命淡退。可保留很短的出生平滑及最终安全清理门。喷沫／水滴分支不因此一并改写。先看修正后的原生结果，再微调局部 alpha；不以增加粒子数量补偿错误相乘。

| 层 | 发射位置／时序 | 尺度、运动、颜色与退场 |
| --- | --- | --- |
| **浪沫，既有层** | 沿用正在去重的 `CrestSpindrift/BurstSheets/BurstDroplets`，仍从主／次浪唇发出。 | 保持较硬亮沫头和细滴。不要为补充雾气再增冠状卡片；这些发射簇只提供后续雾的来源。 |
| **CrestLiftMist，新增 1 系统** | B+0.04s 主浪喷沫簇释放约 8–12 粒；B+0.11s 次浪约 4–6 粒。起点为同一喷沫簇的浪唇，沿外法向离面 0.03–0.06H，不在整条弧等距铺开。 | 初始尺寸 0.22–0.35H，逐渐展开到 0.50–0.70H；切向 0.15–0.25H/s、外向 0.25–0.45H/s、向上 0.30–0.50H/s，前快后慢。寿命 0.45–0.65s。alpha 先在约 0.05s 内升起，再随 atlas 破开／稀释，B+0.80s 前散尽。 |
| **ReturnMist，调整现有系统** | B+0.32–0.55s 分两小簇释放，取主／次喷溅短程轨迹的预计落点并投到受方脚底平面。每簇约 6–10 粒，替换旧的单次统一释放，不叠加两套。 | 高度起点 0.03–0.06H，尺寸约 0.35–0.55H → 0.60–0.85H；外向 0.10–0.22H/s、切向 0.05–0.10H/s、向上 ≤0.04H/s。寿命 0.45–0.60s，B+1.15s 前自然散尽。低雾主体在膝下附近，不能再次升成罩人的大云。 |

落点只需以已知喷溅起点、速度和固定短时视觉轨迹求近似 XZ，再限制在受方视觉范围；不增加碰撞、raycast、真实弹道伤害或新的子发射器链。`GatherMist` 继续低亮汇流，不同步全体增量。

抬升雾暗部起点 `#347582`、受光部 `#C5F4F4`；落点低雾较暗，约 `#2A6675` → `#8AC7CE`。材质 opacity 起点：抬升 0.22–0.32、低雾 0.14–0.22，乘 A 覆盖和粒子颜色 alpha，不再乘 R。数值须在修正重复衰减后重看，不是最终整块不透明度。抬升雾在 B+0.10–0.20s 形成短暂可读的受光团，再迅速变薄；低雾在其实际释放后的前 0.08–0.15s 读出局部落点，然后退去。重点是浪唇后的几簇雾可见，而非提高所有雾的总 alpha。保留暗部和空洞，不把 data.g 直接饱和成白色。

雾使用预乘透明，所有 RGB 与 alpha 一同淡退；不采用 Additive 白雾。允许一个**与短闪同步的局部反光**：仅电弧连接处所在水面的 s 小窗（中心±约0.06–0.10）及浪唇 q 区域，结合既有泡沫／浪唇 mask，增加约 5–12% 的浅青亮度，随两个脉冲归零；不把整张主／次浪再提亮一次。附近抬升雾依其受光通道表现亮团，不做整群雾闪白。关掉新闪电层时，三项水体修正仍必须成立。

## 3. 最小改动与接口

- **Controller**：保留全部 public/gameplay 契约。在 canonical `SlazeyaStormVisualController.cs` 内增电弧节点引用、有限脉冲采样、两个抬升雾释放 latch；扩展 `ParticleNames` 加 `CrestLiftMist`，调整既有 ReturnMist 两簇调度。使用已有 `CrestPoint/ShapePhase/_burstAge`，不另开 Update、协程、`Time.time` 或独立时钟。源镜像按现有机制同步。
- **节点**：`AB_BurstRoot/LightningRoot/{PrimaryBolt,SecondaryBolt}`，初始 renderer 禁用；两变体各含自己的短支链。`AB_ParticleRoot/CrestLiftMist` 使用现有 mist atlas 材质的新实例参数。已有 ReturnMist 节点直接复用。
- **Builder**：在专属 `SlazeyaStormMassBundleBuilder.cs` 内增加短闪 mesh／材质、CrestLiftMist 系统，并绑定现有 atlas；所有新资源纳入同一 Bundle。原生 components／无自定义 MonoBehaviour 校验不变。
- **Shader**：新增小型 `SlazeyaStormLightning.shader`（`Steria/SlazeyaStormLightning`），只做横向白芯／青边、端部羽化、显式 `_Pulse` 和加法混合，正常深度测试、`ZWrite Off`。不导入完整 Plasma shader。现有 `SlazeyaStormParticles.shader` 的雾分支去掉 alpha 中第二次密度相乘，并把雾暗／亮色暴露为材质参数，给抬升与落点分别配置；atlas 解码和年龄流不重写。主水 shader 只增默认为零的局部反光参数（例如 `_LightningPulse/_LightningS`），按上述小窗作用于相应浪面；不改其正在修正的法线、基础调色和几何。
- **清理与验证**：新 renderer 纳入现有 `_renderers/Clear()`；新粒子纳入现有有限手工 `Simulate`，禁止同时自动 Play。重复回调不重置脉冲／补雾；取消立即清理；Tail 到点仍归零。验证器只增加新节点／shader 白名单和有限生命周期检查，不更改 manager 规则或扩建测试体系。

## 4. 原生验收

沿用相同镜头、H、阵型和同源 Bundle 回读路径。复用原序列，提取 **B+0.033 主闪、B+0.067 暗间隔、B+0.117 次闪、B+0.20 水冠、B+0.55 雾层转换、B+0.95 低雾、B+1.25 清空**。GIF／视频必须来自同一原生时间线，不能单帧另调曝光。

动态通过须满足：①只在受方风暴眼／浪唇附近看到一强一弱两次短闪，中间确实暗下，B+0.15 后无电弧，局部反光同窗结束；②水冠是视觉主体，电弧不围满阵地、不把全图照白；③亮浪沫先出，B+0.10–0.20 有可读抬升雾峰，随后在局部落点退成低雾，能追踪来源而非凭空堆云；④暖灰战场上脚底低雾实际可见，不能仍被重复密度相乘压没，也不出现重复冠状喷沫、atlas 串格、柔圆遮罩或全体角色长期被白雾遮住；⑤所有新层最迟 B+1.20s 结束，原三项水体修正和全部既有桥接合同继续成立。
