# 乐章击中跳字：原版盾形抗性样式

用户确认保留音符，改成原版盾形抗性样式；按要求单线程执行设计、实现和单独复核。

当前三个伤害图层都被替换为浅蓝裸音符，原版盾形轮廓、红色体力/金色混乱语义和抗性明暗丢失。依据游戏 `AttackEffectManager.CreateDamagedTextEffect`、`DamageTextEffect.Update`、`DamageNumber` 及游戏序列化的 128px 抗性 atlas。

设计：沿用已有代码作者的同一双音符几何，置于原版比例的拱顶盾形框中；细亮芯、暖色边缘、局部不规则笔触与暗透底。红/金各五级资产对应 Weak、Vulnerable、Normal、Endure、Resist；Immune 与原版一样复用 Resist。运行时只加载嵌入 PNG，保持三图层的原位置、材质、可见性及淡出。

数字、字体、抗性文字、闪白、混乱延迟和飘动完全由原版控制。卡页图标及战斗伤害计算不在修改范围。补丁只处理本次新建跳字，不回退到已存在的其他命中。

验收：同尺度原版/旧版/新版红金对照，五级抗性可辨；完整、半透明、淡出均不出现裸音符三重叠影或攻击符号残影。调用生产视觉代码检查图层状态、幂等和恢复，再执行现有源码检查及 Release build。预览替身不作为完整游戏实战验收。

结果：主线程分开执行实现与视觉复核，首版亮边偏细，修订为较厚的暖色亮边、弱点浅亮边/易损亮底、耐性暗底和抵抗灰暗轮廓。最终 `output/music-damage-native/comparison.png` 同时显示原版、乐章、32px 旧新和三档淡出；源码抽取后的托管夹具 114 项断言通过，覆盖实际生产视觉代码及本次 Harmony Prefix/Postfix。夹具 PNG 解码、组件、颜色与层状态有替身。

Unity 2019 启动被当前许可证阻止，停止了本任务进程；未处理许可证。最终用同一 C# 作者实现的托管宿主离线生成，未执行 GPU 或游戏内实战。Release Rebuild 0 errors，7 项既有 warnings，最终 DLL 十份嵌入资源与源 PNG 哈希逐一匹配。
