# 模组基础结构操作手册

## 标准模组文件夹结构

```
YourModName/
├── Assemblies/
│   ├── YourModDLL.dll              # 编译生成的C#代码
│   └── 1FrameworkAssemblies/       # 框架依赖库
│
├── Data/
│   ├── CardInfo.xml                # 战斗书页定义
│   ├── PassiveList.xml             # 被动能力定义
│   ├── EquipPage_Librarian.xml     # 司书核心书页
│   ├── EquipPage_Enemy.xml         # 敌人核心书页
│   ├── EnemyUnitInfo.xml           # 敌人单位信息
│   ├── StageInfo.xml               # 关卡信息
│   ├── Deck_Enemy.xml              # 敌人卡组
│   ├── CardDropTable.xml           # 卡牌掉落表
│   ├── Dropbook.xml                # 书籍掉落
│   ├── BookStory.xml               # 书籍故事
│   ├── StoryText/                  # 剧情文本（可按 cn/en/kr 分语言目录）
│   └── StoryEffect/                # 剧情演出配置
│
├── Localize/
│   ├── cn/
│   │   ├── BattlesCards/           # 卡牌名称描述，按当前 BaseMod 的目录名保留 s
│   │   ├── BattleCardAbilities/    # 骰子效果描述
│   │   ├── PassiveDesc/            # 被动描述
│   │   ├── Books/                  # 核心书页描述
│   │   └── EffectTexts/            # Buff效果文本
│   ├── en/
│   └── kr/
│
├── Resource/
│   ├── CombatPageArtwork/          # 卡牌图片 (.png)
│   ├── AssetBundle/                # Unity资源包 (.ab)
│   ├── CustomAudio/                # 自定义音效
│   └── Stage/                      # 关卡背景
│
├── StageModInfo.xml                # 模组信息文件
└── preview.jpg                     # 预览图
```

## StageModInfo.xml 模板

```xml
<?xml version="1.0" encoding="utf-8"?>
<ModInfo>
  <ModId>YourModId</ModId>
  <Title>模组标题</Title>
  <Desc>模组描述</Desc>
  <Version>1.0</Version>
</ModInfo>
```

## ID命名规范

| 类型 | ID格式 | 示例 |
|------|--------|------|
| 被动 | 纯数字，建议9000000+ | `9000001` |
| 卡牌 | 纯数字，建议9000000+ | `9000101` |
| 核心书页 | 纯数字，建议10000000+ | `10000001` |
| 敌人单位 | 纯数字 | `9000001` |
| 关卡 | 纯数字 | `9000001` |

## 游戏内文案与配置的标点规范

**先区分玩家可见的中文正文与机器解析字段。** 本项目新增或修改的卡面规则、状态说明、剧情对白等中文正文使用自然的全角中文标点；XML 标签/属性、ID、路径、代码、关键词高亮标记和格式占位符保持各自的机器语法。XML 能读入中文标点，但最终换行与高亮仍要在 UI 检查。

| 所在字段 | 推荐写法 | 注意事项 |
|---|---|---|
| 玩家可见中文正文 | `，。；：！？（）“”……` | 按语气与排版使用，不整段强制替换成英文标点 |
| 正文关键词高亮 | `[关键词]` | 半角方括号是解析标记；其中显示名可为中文 |
| 格式占位符 | `{0}` | 花括号和序号保持解析器要求的 ASCII 形式 |
| XML/代码/ID/路径 | `< > / = "` 等语法字符 | 属性引号与正文引号分开处理，必要时转义 |

例如规则正文写作：`[使用时]获得２层[霜痕]，下回合失去１层。`。显示标点和数量可按中文排版处理；`[ ]` 仍必须是半角语法字符。

这里需要区分两件事：

- **项目文案规范：** 玩家可见中文使用全角中文标点；审核时检查语气、断句、换行与字形，而不做无差别字符替换。
- **解析器硬要求：** XML 的 `< > / = "`、关键词高亮的 `[ ]`、格式占位符 `{0}` 以及代码/标识符必须使用对应语法字符。原版 `TextUtil.TransformConditionKeyword` 只替换半角 `[ ]`，不会把 `【】` 或 `［］` 识别成同一种标记。XML 本身支持中文正文，不应把文案规范解释为“XML 无法保存中文标点”。

在生成、复制或编辑文案后，逐字段检查标点与成对语法；XML 文本中的 `&`、`<` 等按需要写成 `&amp;`、`&lt;`。格式占位符用 `{0}`，不写 `｛０｝`。检查结论和具体文件/条目写入本次主日志，随后在模拟 UI 中确认无原样残留标记、缺字或错误换行。关键词的显示与说明绑定详见[第 02 章第八节](02_战斗书页完整制作.md)。

## 必要的引用DLL

编译C#代码时需要引用以下DLL：

- `Assembly-CSharp.dll` - 游戏主程序集
- `0Harmony.dll` - Harmony库
- `BaseMod.dll` - BaseMod框架
- `UnityEngine.CoreModule.dll` - Unity核心
