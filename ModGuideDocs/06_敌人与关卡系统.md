# 敌人与关卡系统操作手册

## 一、敌人单位定义 (EnemyUnitInfo.xml)

### 基础结构

```xml
<?xml version="1.0" encoding="utf-8"?>
<EnemyUnitClassRoot>
  <EnemyUnit ID="9000001">
    <Name>敌人名称</Name>
    <NameID>MyMod_Enemy01</NameID>
    <MinHeight>180</MinHeight>
    <MaxHeight>190</MaxHeight>
    <BookId>10000001</BookId>
    <DeckId>9000001</DeckId>
    <DropTable>9000001</DropTable>
  </EnemyUnit>
</EnemyUnitClassRoot>
```

### 属性说明

| 标签 | 说明 |
|------|------|
| `BookId` | 关联的核心书页ID |
| `DeckId` | 关联的卡组ID |
| `DropTable` | 关联的掉落表ID |
| `MinHeight/MaxHeight` | 身高范围（影响模型缩放） |

## 四、剧情制作与接待绑定(StoryText / StoryEffect)

参考: `寒昼事务所V4.0` 的 `Data/StageInfo.xml`, `Data/StoryText/`, `Data/StoryEffect/`.

### 1) 在 StageInfo.xml 绑定剧情

使用 `<Story>` 绑定开场与结尾剧情, 并指定 `<StoryType>`:

```xml
<Stage id="1">
  <Name>寒昼0</Name>
  <Chapter>6</Chapter>
  <Story Condition="Start">ColdSun_HZ1.xml</Story>
  <Story Condition="End">ColdSun_HZ1_END.xml</Story>
  <StoryType>HZStory_HZ</StoryType>
  ...
</Stage>
```

要点:
- `Condition="Start"` 表示接待开始剧情, `Condition="End"` 表示接待结束剧情.
- `Story` 填文件名(含扩展名). 加载时按“文件基础名”匹配, 所以 `.xml` 或 `.txt` 都可.
- `StoryType` 用于区分剧情组(可自定义字符串, 与同组关卡保持一致).

### 2) StoryText(剧情文本)文件

路径: `Data/StoryText/`.

最小模板(参考 `寒昼事务所V4.0/Data/StoryText/测试.xml`):

```xml
<?xml version="1.0" encoding="utf-8"?>
<ScenarioRoot xmlns:xsd="http://www.w3.org/2001/XMLSchema" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance">
  <Chapter ID="-1">
    <Title />
  </Chapter>
  <Group>
    <GroupName>group</GroupName>
    <Episode>
      <EpisodeName>Episode</EpisodeName>
      <Place>
        <PlaceName>Place</PlaceName>
        <Dialog ID="0" Model="">
          <Teller />
          <Title />
          <Content />
        </Dialog>
      </Place>
    </Episode>
  </Group>
</ScenarioRoot>
```

要点:
- `Dialog ID` 必须与 StoryEffect 中的 `Dialogue ID` 对应, 否则表现对不上.
- 一个剧情文件可以包含多个 Place 与 Dialog.

多语言支持(BaseMod):
- BaseMod 会优先读取 `Data/StoryText/<语言>/` 下与基础名相同的文件.
- 若当前语言目录不存在, 会回退到 `BasemodConfig.DefaultLocale`.
- 建议结构: `Data/StoryText/cn/xxx.xml`, `Data/StoryText/en/xxx.xml` 等.

### 3) StoryEffect(演出效果)文件

路径: `Data/StoryEffect/`.

最小模板(参考 `寒昼事务所V4.0/Data/StoryEffect/测试.xml`):

```xml
<?xml version="1.0" encoding="utf-8"?>
<SceneEffect xmlns:xsd="http://www.w3.org/2001/XMLSchema" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance">
  <CG />
  <storyBranch>None</storyBranch>
</SceneEffect>
```

常见用法:
- `Dialogue ID` 与 StoryText 的 `Dialog ID` 一一对应.
- 可配置 `Bg`, `Bgm`, `Filter`, `CharacterList`, `EffectSound` 等演出元素.
- 若不需要复杂演出, 保留最小模板即可避免报错.

### 4) CG 与背景图绑定

若在 StoryEffect 中使用 `<CG Src="xxx" />`:
- 将 CG 图片放在 `Resource/StoryBgSprite/`.
- 文件名需与 `Src` 对应(不含扩展名或直接写完整文件名均可, 参考寒昼项目用法).
- BaseMod 会在剧情面板中加载对应 CG.

### 5) 战前、战后剧情的完整目录示例

```text
YourMod/
└── Data/
    ├── StageInfo.xml
    ├── StoryText/
    │   ├── MyStage_Start.xml       # 无多语言时也可直接放在根目录
    │   ├── MyStage_End.xml
    │   ├── cn/
    │   │   ├── MyStage_Start.xml
    │   │   └── MyStage_End.xml
    │   └── en/
    │       ├── MyStage_Start.xml
    │       └── MyStage_End.xml
    └── StoryEffect/
        ├── MyStage_Start.xml
        └── MyStage_End.xml
```

`StoryText` 位于 `Data/StoryText/`, 不在 `Localize/<语言>/StoryText/` 中. `StoryEffect` 通常不按语言拆分.

BaseMod 的加载顺序为:

1. 尝试 `Data/StoryText/<当前语言>/<文件名>`.
2. 当前语言目录不存在时, 尝试 `BasemodConfig.DefaultLocale` 对应的目录.
3. 没有匹配的语言文件时, 使用 `Data/StoryText/` 根目录下的文件.

`Condition="Start"` 在接待开始前播放; `Condition="End"` 在整场接待胜利结束后播放, 并不是每个 Wave 结束后播放. 若要在换阶段、换 Wave 或指定幕中播放, 使用下一节的 C# 触发方式.

### 6) 战中播放完整剧情界面

战中完整剧情仍使用同一套 `StoryText + StoryEffect`, 区别是不能只靠 `StageInfo.xml` 声明, 必须在关卡管理器、被动或书页效果中判断条件并主动打开 `BattleStoryUI`.

下面的帮助方法优先读取当前语言文件, 找不到时回退到 `StoryText` 根目录:

```csharp
using System.IO;
using Mod;
using UnityEngine;

public static class BattleStoryHelper
{
    public static bool Play(string packageId, string storyName,
        BattleStoryUI.OnEndStoryFunc onEnd = null)
    {
        string modPath = Singleton<ModContentManager>.Instance
            .GetModPath(packageId);

        string localizedPath = Path.Combine(
            modPath,
            "Data",
            "StoryText",
            TextDataModel.CurrentLanguage,
            storyName + ".xml"
        );

        string fallbackPath = Path.Combine(
            modPath,
            "Data",
            "StoryText",
            storyName + ".xml"
        );

        string storyPath = File.Exists(localizedPath)
            ? localizedPath
            : fallbackPath;

        string effectPath = Path.Combine(
            modPath,
            "Data",
            "StoryEffect",
            storyName + ".xml"
        );

        if (!File.Exists(storyPath) || !File.Exists(effectPath))
        {
            Debug.LogError("剧情文件不存在: " + storyName);
            return false;
        }

        if (!StorySerializer.LoadStoryFile(storyPath, effectPath, modPath))
        {
            Debug.LogError("剧情加载失败: " + storyName);
            return false;
        }

        SingletonBehavior<BattleManagerUI>.Instance.ui_battleStory.OpenStory(
            onEnd ?? new BattleStoryUI.OnEndStoryFunc(() => { }),
            false,  // false: 允许跳过
            true    // true: 播放期间阻塞战斗
        );
        return true;
    }
}
```

在关卡管理器中于第 3 幕开始时播放一次:

```csharp
public class EnemyTeamStageManager_MyStage : EnemyTeamStageManager
{
    private bool _midStoryPlayed;

    public override void OnRoundStart()
    {
        base.OnRoundStart();

        if (_midStoryPlayed)
            return;

        if (Singleton<StageController>.Instance.RoundTurn == 3)
        {
            _midStoryPlayed = true; // 打开剧情前先置位, 防止重复进入
            BattleStoryHelper.Play("YourModId", "MyStage_Mid");
        }
    }
}
```

也可以从被动或书页效果中调用同一个帮助方法. 常用触发位置:

| 需求 | 推荐回调 |
|------|----------|
| 进入当前 Wave 时 | `EnemyTeamStageManager.OnWaveStart()` |
| 指定幕开始时 | `OnRoundStart()` |
| 本幕全部行动结束后 | `OnRoundEndTheLast()` |
| Boss 血量进入某阶段 | `OnRoundEnd()` 中检查 HP 比例 |
| 使用指定书页后 | `DiceCardSelfAbilityBase.OnUseCard()` 或书页演出协程 |
| 某单位死亡时 | `EnemyTeamStageManager.OnDie()` |

注意:

- 必须使用布尔字段或阶段枚举防止剧情重复触发.
- 如果播放前主动停止了 BGM、切换了战斗阶段或隐藏了单位, 要在 `onEnd` 回调中恢复.
- `OpenStory(..., false, true)` 的第三个参数表示剧情期间阻塞战斗; 战中剧情通常应设为 `true`.
- 若需要在某一行对白出现时执行动作, 可在打开剧情后调用 `ui_battleStory.AddEvent(dialogId, action)`; `dialogId` 对应 `StoryText` 中的 `Dialog ID`.

仓库中的实战参考:

- `寒昼事务所V4.0/unpack/ColdSun/HZ_Core/PassiveAbility_ColdSun_Atiluoka3_01.cs`: 在 `OnRoundEndTheLast()` 中触发剧情.
- `寒昼事务所V4.0/unpack/ColdSun/HZ_Core/DiceAttackEffect_EGO_Atiluoka_ChangeSkin03.cs`: 在书页演出协程中加载剧情并打开 `BattleStoryUI`.
- `寒昼事务所V4.0/unpack/ColdSun/ColdSun/UnitInfoUtil.cs`: `AddBattlePreStory` 封装示例.

### Boss战阶段管理

```csharp
public class EnemyTeamStageManager_MyMod_Boss : EnemyTeamStageManager
{
    private int _phase = 1;
    private BattleUnitModel _boss;

    public override void OnWaveStart()
    {
        base.OnWaveStart();
        _boss = BattleObjectManager.instance.GetAliveList(Faction.Enemy)
            .FirstOrDefault(x => x.UnitData.unitData.EnemyUnitId == 9000004);
        _phase = 1;
    }

    public override void OnRoundEnd()
    {
        base.OnRoundEnd();

        if (_boss == null || _boss.IsDead()) return;

        // 阶段转换
        float hpRatio = (float)_boss.hp / _boss.MaxHp;

        if (_phase == 1 && hpRatio <= 0.7f)
        {
            _phase = 2;
            EnterPhase2();
        }
        else if (_phase == 2 && hpRatio <= 0.3f)
        {
            _phase = 3;
            EnterPhase3();
        }
    }

    private void EnterPhase2()
    {
        // 第二阶段效果
        _boss.bufListDetail.AddKeywordBufThisRoundByEtc(KeywordBuf.Strength, 2, _boss);
        _boss.RecoverHP(30);

        // 召唤增援
        // ...
    }

    private void EnterPhase3()
    {
        // 第三阶段效果
        _boss.bufListDetail.AddKeywordBufThisRoundByEtc(KeywordBuf.Strength, 3, _boss);
        _boss.bufListDetail.AddKeywordBufThisRoundByEtc(KeywordBuf.Endurance, 3, _boss);
    }
}
```

## 八、召唤增援

```csharp
public class EnemyTeamStageManager_MyMod_Summon : EnemyTeamStageManager
{
    public override void OnRoundStart()
    {
        base.OnRoundStart();

        // 每3幕召唤一次增援
        if (Singleton<StageController>.Instance.RoundCount % 3 == 0)
        {
            SummonReinforcement();
        }
    }

    private void SummonReinforcement()
    {
        // 获取空位
        int emptyPos = GetEmptyPosition();
        if (emptyPos < 0) return;

        // 召唤单位
        var unitId = new LorId("MyModId", 9000002);
        var unit = Singleton<StageController>.Instance.AddNewUnit(
            Faction.Enemy,
            unitId,
            emptyPos
        );

        if (unit != null)
        {
            // 设置初始状态
            unit.bufListDetail.AddKeywordBufThisRoundByEtc(KeywordBuf.Strength, 1, unit);
        }
    }

    private int GetEmptyPosition()
    {
        var enemies = BattleObjectManager.instance.GetAliveList(Faction.Enemy);
        var usedPositions = enemies.Select(x => x.index).ToHashSet();

        for (int i = 0; i < 5; i++)
        {
            if (!usedPositions.Contains(i))
                return i;
        }
        return -1;
    }
}
```

## 十二、战斗对话 (Combat_Dialog.xml)

战斗对话是显示在角色头像旁的短台词, 不会打开完整剧情界面. 它适合战斗开始、胜利、死亡、击杀和阶段转换提示. 若需要可点击推进、有立绘与背景的完整剧情, 使用“四、剧情制作与接待绑定”中的方法.

```xml
<?xml version="1.0" encoding="utf-8"?>
<BattleDialogRoot>
  <Version>1.1</Version>
  <Character ID="9000001">
    <Type ID="START_BATTLE">
      <BattleDialog ID="START_BATTLE_0">战斗开始了...</BattleDialog>
    </Type>
    <Type ID="BATTLE_VICTORY">
      <BattleDialog ID="BATTLE_VICTORY_0">我赢了。</BattleDialog>
    </Type>
    <Type ID="DEATH">
      <BattleDialog ID="DEATH_0">不可能...</BattleDialog>
    </Type>
    <Type ID="COLLEAGUE_DEATH">
      <BattleDialog ID="COLLEAGUE_DEATH_0">你不会白白牺牲。</BattleDialog>
    </Type>
    <Type ID="KILLS_OPPONENT">
      <BattleDialog ID="KILLS_OPPONENT_0">下一个。</BattleDialog>
    </Type>
    <Type ID="SPECIAL_EVENT">
      <BattleDialog ID="SPECIAL_EVENT_0">接下来才是真正的战斗。</BattleDialog>
      <BattleDialog ID="SPECIAL_EVENT_1">局势已经改变了。</BattleDialog>
    </Type>
  </Character>
</BattleDialogRoot>
```

`Character ID` 通常与敌人核心书页或敌人单位所使用的对话 ID 对应. 当前 `SteriaModFolder` 中敌人 ID、敌人核心书页 ID 与 `Character ID` 使用了相同的小整数, BaseMod 会据此建立关联.

标签名必须是 `BattleDialog`, 不是 `Dialog`. `DialogType` 的反序列化定义使用 `[XmlElement("BattleDialog")]`; 写成 `Dialog` 时台词不会进入对话列表.

以下类型由游戏在相应事件中自动触发:

| Type ID | 触发时机 |
|---------|----------|
| `START_BATTLE` | 战斗开始 |
| `BATTLE_VICTORY` | 战斗胜利 |
| `DEATH` | 本单位死亡 |
| `COLLEAGUE_DEATH` | 同伴死亡 |
| `KILLS_OPPONENT` | 击杀对手 |

`SPECIAL_EVENT` 不会自动触发, 需要在 C# 中指定台词 ID:

```csharp
owner.view.DisplayDlg(
    DialogType.SPECIAL_EVENT,
    "SPECIAL_EVENT_0"
);
```

例如第 3 幕只触发一次特殊台词:

```csharp
private bool _specialDialogPlayed;

public override void OnRoundStart()
{
    base.OnRoundStart();

    if (!_specialDialogPlayed &&
        Singleton<StageController>.Instance.RoundTurn == 3)
    {
        _specialDialogPlayed = true;
        owner.view.DisplayDlg(
            DialogType.SPECIAL_EVENT,
            "SPECIAL_EVENT_0"
        );
    }
}
```

若调用后没有显示, 依次检查:

1. `StageModInfo.xml` 中的 `<Dialog Exist="true">` 是否指向该文件.
2. XML 是否使用 `BattleDialog` 标签.
3. `Character ID` 是否与当前单位/核心书页的对话关联一致.
4. C# 传入的字符串是否与 `BattleDialog ID` 完全相同.
5. 当前关卡是否为 `StageType.Invitation`; `BattleUnitView.DisplayDlg` 对邀请关卡读取 `battleDialogModel`.
