# 自律发明接待

2026-10-26 平衡修订：敌方六个位置容纳塔菲、蒸汽工坊与四个机关。司书出战上限仍为五人。敌方站位固定为左侧工坊、中间塔菲、右侧四机关组成2×2四边形。机关补位复用原角点；对BaseMod预先扩展的100槽阵型也会重新定位前六槽，避免第六槽沿用右上角默认坐标。

发明进度达到5层时清空并记录机关，于下一幕开始时统一召唤，登场当幕即可参与配牌。幕开始自动获得的进度若触发完成，也要等再下一幕登场。在场与待登场机关合计至多四个，名额已满时改为让当前所有友方下一幕各自随机获得3层强壮、迅捷或守护，不保留满额后的召唤积压。待登场机关不提供增益，状态栏显示待登场数量。

25种组合的体力和混乱抗性，按上一版各组合最终整数值乘0.8后四舍五入。类型基准现在为：机关120/64、连锁112/60、防御144/80、毁灭116/56、能源104/68。抗性与词条倍率关系不变，固定两颗速度骰。

| 类型 | 对其他友方的在场支援 | 远程书页 |
|---|---|---|
| 机关 | 其他机关伤害+15% | 无 |
| 连锁 | 其他机关混乱伤害+15% | 连锁电弧 |
| 防御 | 其他全部友方获得2层持续守护 | 无 |
| 毁灭 | 其他机关进攻型骰子最大值+1 | 破甲爆裂 |
| 能源 | 其他机关所有骰子威力+1 | 增压喷流 |

同类支援叠加，超级机关的支援翻倍。防御支援沿用八重庇护的原版 StatBonus.dmgAdder 语义，作为持续守护等价减伤，与普通守护叠加；来源死亡立即失效，不依赖幕开始顺序，不会施加给来源自身。

词条增益：奇特→速度+1；诡异→每张书页首次命中施加下幕1虚弱；脆弱→伤害及混乱伤害+15%；神秘→防御型骰子威力+1；超级→进攻型骰子威力+1。每个机关登场时增加1层，之后每幕开始时再增加1层，增益按机关独立存储。对应机关被击败时移除自身提供的全部层数，其他机关的层数不受影响；重复死亡通知不重复移除。

工坊先于塔菲被击败时，立即取消已排定的发明，永久摧毁塔菲两颗速度骰子，清除进度及待登场机关并停止发明。现有机关继续行动及提供支援。八重庇护的击杀计数规则保持不变，工坊死亡与塔菲死亡后的清场不计数。

中文术语参考本机游戏 resources.assets 中的原版简体中文，相关状态节选保存在 `native-cn-effects.xml`。统一使用“这一幕／下一幕”“进攻型／防御型骰子”、明确下一幕状态时机及全角中文标点；XML ID、数字与方括号标记保持解析格式。

## 复现

```powershell
python AceTaffy/generate_invention_units.py
./AceTaffy/build.ps1
./AceTaffy/Verification/Reception/run_fixture.ps1
```

每次运行在 `output/<时间>/` 保存 `unity.log` 和 `candidate.json`（DLL、源码、数据、本地化与测试代码哈希），以 `RECEPTION_PASS` 为通过标记。

覆盖真实生产DLL、原版XML／能力工厂／速度规则／状态晋升／书页续攻队列；核验25组减值、三张远程书页、真实BaseMod阵型扩展、1／1／4站位、归位和补位、六槽阵型与原版面板/情感硬币列表的第六单位绑定、机关下一幕登场及当幕配牌、幕开始完成后再延迟一幕、待登场名额与死亡取消、满场奖励延迟、增益跨幕独立累积与死亡移除全部层数、临场发明固定最低两颗速度骰、实时支援、工坊死亡停机、原发明拦截与光芒预算。
