# 战斗书页重绘

使用内置 image_gen，人物以 `../../永雏塔菲-参考图.png` 为身份和正常头身比例参考，机关以 `../Character/invention-units/unit_0_0.png` 至 `unit_0_4.png` 为造型参考。母图均为 1448×1086（4:3）；`../../normalize_ui_art.py` 输出 512×384 游戏资源。

共同提示：横向 4:3、无文字边框，主体与动作、主要物品占据画面，背景简化；人物遵循参考图身形，避免大头娃娃，手绘动画风与清晰轮廓。机关保留对应齿轮、装甲、线圈或履带造型。

人物动作与表情：点火（点燃引火装置，温和好奇）、黄铜铆钉（瞄准铆钉枪，专注）、废汽回收（操作冷凝器，轻微满意）、活塞连动（活塞击打，坚决）、烟道逆流（拉动换向杆，思索）、安全阀测试（转阀，轻微惊讶）、锅炉装甲（交叉防御，沉着）、超临界运转（操作过载锅炉，紧张专注）、蒸汽爆轰（发射蒸汽炮，坚定）、临场发明（扳手装配，凝神）。人物卡图先生成动作场景，再按各动作调整表情，保留造型和构图。

机关动作：棘轮连打（多次挥锤）、回转重锤（下砸）、拖曳锁链（牵引链条）、连锁电弧（线圈放电）、展开壁垒（展开盾面）、盾面镇压（盾击）、破甲爆裂（发射穿甲弹）、过载冲撞（冲锋）、废汽虹吸（吸入烟气）、增压喷流（喷出蒸汽）。每张书页使用独立图。
