# AceTaffy ０．２．３交付记录

本版按用户反馈修正废汽回收，并简化烟气相关文案。

## 改动

废汽回收只消耗３层普通烟气，成功后抽取２张书页并获得３层蒸汽压力。普通烟气不足３层时，不消耗压力，也不发放使用时奖励；骰子自身的效果照常处理。

烟气相关文案统一使用烟气名称，移除反复解释计数实现的句子。恢复原版烟气说明和原版书页关键词说明，状态栏继续分别显示烟气与压力层数。

本模组中文正文使用全角标点，正文关键词保留原生半角方括号语法。卡面、能力本地化与数据中的备用说明保持一致。

修正卡片本地化的实际加载路径与结构：使用 `Localize/cn/BattlesCards/`、`BattleCardDescRoot`、`LocalizedName` 和 `Ability`，避免名称与说明因旧格式被忽略。

## 验证与边界

主线程已检查机制实现，并运行引用真实游戏程序集的机制探针，６７项检查通过。覆盖回收支付及奖励、原版计数与伤害接口、说明未被替换、独立层数数据，以及既有的拼点和单方面复投路径。

机制探针使用实际回收能力类和原生烟气类型；抽牌回调、随机骰值及部分界面依赖使用隔离替代，因此检查的是奖励请求和规则结果，不能等同于完整游戏战斗。未启动用户游戏，实际界面排版和完整实战由用户验收。

生产候选的 Release 构建、包校验、部署位置及文件哈希记录在本轮主日志和发布清单中。规则契约及第四章的消耗例外指导已同步。
